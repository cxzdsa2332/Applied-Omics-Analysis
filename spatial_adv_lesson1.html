Published

47 专题概述

第 8 章的基础流程止步于一个未解的核心问题：Visium 的每个 Spot 是多细胞混合信号，聚类给出的空间域只说明”这片区域的转录特征相似”，却没有回答”这里住着哪些细胞类型、各占多少”。细胞解卷积（Cell Type Deconvolution）正是为回答后者而生——借助已知细胞类型转录特征的 scRNA-seq 参考，把每个 Spot 的混合信号反解为各细胞类型的丰度向量。这在数学上是一个有约束的混合模型反演问题，而这一表述立即揭示了它的软肋：反演的质量完全取决于特征谱的准确性与完备性。本专题系统讲解解卷积的方法谱系与实操，并用相当篇幅讨论一个常被忽略却更重要的问题——如何验证解卷积的结果是否可信。

学习目标：掌握解卷积的数学表述与约束条件；理解参考图谱的三项质量要求及其失效后果；掌握 RCTD、cell2location、Tangram、CARD 四类方法的统计框架与适用场景；能完成 cell2location 两阶段流程与 RCTD 的 R 实操；理解绝对丰度与相对比例两种输出的解读差异；掌握模拟 Spot 基准、标志基因一致性、后验不确定性三种验证策略；能识别解卷积失败的典型征象。

48 解卷积问题的数学表述

48.1 一个混合模型的反演

设某个 Spot \(s\) 观测到的表达向量为 \(\mathbf{y}_s \in \mathbb{R}^G\)（\(G\) 为基因数），参考中第 \(k\) 种细胞类型的平均表达谱（签名）为 \(\mathbf{g}_k \in \mathbb{R}^G\)，则解卷积模型的基本形式是：

\[\mathbf{y}_s = \sum_{k=1}^{K} \beta_{sk}\, \mathbf{g}_k + \boldsymbol{\epsilon}_s, \qquad \beta_{sk} \geq 0\]

其中 \(\beta_{sk}\) 是待求的、细胞类型 \(k\) 在 Spot \(s\) 中的丰度。两个约束是本质的：非负性（丰度不能为负）与视输出定义而定的归一化（若输出相对比例则 \(\sum_k \beta_{sk} = 1\)，若输出绝对丰度则不归一）。

这个式子看起来只是一个非负最小二乘问题，但实际难点在三处：

  1. \(\mathbf{g}_k\) 不是已知常量，而是从另一批数据（scRNA-seq 参考）估计出来的，本身带有误差与批次效应。
  2. 噪声 \(\boldsymbol{\epsilon}_s\) 不是高斯的。表达数据是计数，方差随均值增长，必须用泊松或负二项建模。
  3. 模型可能设定错误。若参考缺少某个实际存在的细胞类型，模型中就不存在对应的 \(\mathbf{g}_k\)，而算法仍会强行给出一组非负解——把缺失类型的信号分摊到最相似的已有类型上。

第三点是解卷积最危险的失效模式，因为它不会报错，只会安静地给出一个看似合理的错误答案。

48.2 参考图谱的三项要求

由上述分析，参考 scRNA-seq 必须满足三项要求，缺一不可：

  • 同源性：同物种、同组织，最好同发育阶段与病理状态。用健康脑的参考去解卷积肿瘤组织，必然失败。
  • 完备性：覆盖目标组织中实际存在的所有细胞类型。这一点无法从数据本身验证，只能依靠对组织生物学的了解。
  • 充分性：每种细胞类型至少有数十个细胞（通常建议 ≥ 50）以稳定估计其签名。细胞数太少的稀有类型，其签名噪声大，会污染整个反演。

参考图谱不匹配是解卷积最大的失败来源： 若参考 scRNA-seq 缺少目标组织中实际存在的某种细胞类型，解卷积无法”凭空”识别它，只会把它的信号错误地分摊给签名最相似的已有类型，产生系统性偏差。因此参考必须来自同种、同组织（最好同发育阶段/病理状态），且覆盖所有预期细胞类型，每种类型至少有数十个细胞以稳定估计签名。盲目套用不匹配的公共参考会得到看似合理实则错误的空间分布——而且由于结果”看起来很像那么回事”，这类错误极难在事后被发现。

49 方法谱系

49.1 三代方法的演进

细胞解卷积工具按统计复杂度大致可分为三代，表 1 做了系统对比。

  • 基于线性回归（RCTD、SPOTlight）：假设 Spot 表达是各细胞类型签名的线性加权和，用带稳健性处理的回归求解权重。RCTD（Robust Cell Type Decomposition）用泊松最大似然建模，并提供 doublet_mode，假设每个 Spot 至多由两种主要细胞类型构成——这一假设适合分辨率较高、每个单元只覆盖少数细胞的平台（如 Slide-seq），在标准 Visium 上通常应改用 full 模式（Cable et al., 2022）。SPOTlight 则用非负矩阵分解（NMF）以细胞类型标签作为种子初始化，再做非负最小二乘。
  • 基于概率生成模型（cell2location）：用层次贝叶斯模型，显式建模技术批次、每个 Spot 的捕获效率与细胞类型丰度，精度高且能给出完整的后验不确定性估计（Kleshchevnikov et al., 2022）。
  • 基于深度学习（Tangram）：不估计比例，而是学习一个把单细胞”映射”到空间位置的概率矩阵，灵活但可解释性较弱。

{{Wiki:Non-negative_matrix_factorization}} {{Wiki:Bayesian_hierarchical_modeling}}

此外还有一类值得单独提及的方法：CARD 引入条件自回归（Conditional Autoregressive, CAR）先验，利用”相邻 Spot 的细胞组成应当相似”这一空间平滑性假设——这与第 8 章 BayesSpace 的 MRF 先验是同一思想在解卷积问题上的应用（Ma & Zhou, 2022）。

没有普遍最优的方法，但有普遍必要的验证： 多项独立基准研究比较过上述方法，结论随评测数据集与指标而变化，并不存在一个在所有场景下占优的工具。与其纠结选哪个，不如把精力放在两件更有回报的事上：一是保证参考图谱的质量（这比换算法的影响大得多），二是对结果做本专题后半部分讲的三类验证。一个务实的做法是用两种原理不同的方法（如 RCTD 与 cell2location）各跑一遍，把结论限定在二者一致的部分。

50 cell2location 实操

50.1 两阶段框架的设计逻辑

cell2location 把解卷积分解为两个独立训练的阶段，这一设计兼顾了准确性与可迁移性：

  1. 第一阶段：学习细胞类型签名。在带注释的 scRNA-seq 参考上，用负二项回归估计每种细胞类型每个基因的参考表达水平（签名矩阵），并把实验批次作为协变量纳入，以消除参考数据自身的技术差异。这一阶段只依赖 scRNA 参考，与具体空间数据无关，因此签名矩阵可复用于同组织的多个空间切片。
  2. 第二阶段：估计空间丰度。固定第一阶段的签名矩阵，用层次贝叶斯模型推断每个 Spot 中各细胞类型的绝对丰度。模型显式建模了每个 Spot 的总 RNA 捕获效率与技术背景，从而把”细胞类型丰度”与”捕获效率”两个混杂因素分离开。

第二点是 cell2location 区别于回归类方法的关键。回归方法输出的是比例（各类型占该 Spot 的百分比），而比例是组成数据——一种细胞类型的比例上升必然意味着其余类型的比例下降，即便后者的绝对数量并未改变。cell2location 通过显式建模捕获效率，输出的是绝对细胞数量的估计，避免了这一组成性约束带来的误读。

运行环境说明： cell2location 是 Python 包（pip install cell2location），基于 scvi-tools 与 PyTorch，强烈建议在 GPU 环境运行；CPU 上训练可能需要数小时。输入为 AnnData 格式的 scRNA 参考（sc_ref.h5ad，含 cell_type 注释）与 Visium 数据（visium.h5ad）。参考数据应使用原始计数而非归一化值。本示例展示核心 API，省略了完整的训练超参数调优与收敛诊断。

import cell2location
import scanpy as sc
from cell2location.models import RegressionModel, Cell2location

# ---- Stage 1: estimate per-cell-type reference signatures from scRNA-seq ----
adata_ref = sc.read_h5ad("sc_ref.h5ad")

# Filter genes: cell2location expects raw counts and a permissive gene set
from cell2location.utils.filtering import filter_genes
selected = filter_genes(adata_ref, cell_count_cutoff=5,
                        cell_percentage_cutoff2=0.03, nonz_mean_cutoff=1.12)
adata_ref = adata_ref[:, selected].copy()

RegressionModel.setup_anndata(adata_ref, batch_key="batch", labels_key="cell_type")
ref_model = RegressionModel(adata_ref)
ref_model.train(max_epochs=250)
adata_ref = ref_model.export_posterior(adata_ref)

# Reference signature matrix: mean expression per gene per cell type
inf_signatures = adata_ref.varm["means_per_cluster_mu_fg"]
# Always check convergence before trusting the signatures
ref_model.plot_history(20)

50.2 第二阶段与两个关键先验

# ---- Stage 2: estimate per-spot cell-type abundances on the Visium data ----
adata_vis = sc.read_h5ad("visium.h5ad")

# Restrict to genes shared between reference and spatial data
shared = adata_vis.var_names.intersection(inf_signatures.index)
adata_vis = adata_vis[:, shared].copy()
inf_signatures = inf_signatures.loc[shared, :]

Cell2location.setup_anndata(adata_vis, batch_key="sample")

# N_cells_per_location and detection_alpha are the two key priors:
#   - N_cells_per_location: expected cells per spot (tissue-dependent, ~8 for brain)
#   - detection_alpha: regularization of per-spot detection efficiency
#       low  (~20): strong regularization, use when technical variation is high
#       high (~200): weak regularization, use when tissue is technically uniform
mod = Cell2location(
    adata_vis,
    cell_state_df=inf_signatures,
    N_cells_per_location=8,
    detection_alpha=20,
)
mod.train(max_epochs=30000, batch_size=None, train_size=1)
adata_vis = mod.export_posterior(adata_vis)

N_cells_per_location 应根据组织类型估计——最可靠的做法是在 H&E 图像上数几个 Spot 覆盖范围内的细胞核数量，取中位数。这个先验不需要非常精确，但数量级错误（如脑组织填 1 或 50）会明显影响结果。

#| label: fig-cell2location-abundance
#| fig-cap: "cell2location 推断的细胞类型空间丰度（stxBrain Visium 小鼠脑）。每个子图为一种细胞类型的后验丰度空间热图，颜色越亮表示该 Spot 中该细胞类型的估计丰度越高。兴奋性神经元、抑制性神经元与星形胶质细胞呈现与已知脑区解剖结构一致的分层分布，验证了解卷积结果的生物学可靠性。"
import scanpy as sc

# Posterior means of cell abundance, written back into adata.obs
adata_vis.obs[adata_vis.uns["mod"]["factor_names"]] = \
    adata_vis.obsm["q05_cell_abundance_w_sf"]

sc.pl.spatial(
    adata_vis,
    color=["Excitatory_neurons", "Inhibitory_neurons", "Astrocytes"],
    ncols=3,
    size=1.3,
    save="_cell2location_abundance.png",
)

50.3 R 路线：RCTD

R 用户可使用 spacexr 包的 RCTD 作为等价方案。它的流程更短，计算也更轻，适合作为快速的第一遍分析或 cell2location 结果的交叉验证。

运行环境说明： spacexr 需从 GitHub 安装（devtools::install_github("dmcable/spacexr")），不在 CRAN/Bioconductor 上。RCTD 在标准 Visium 切片上于多核 CPU 通常数分钟至半小时完成，不需要 GPU。参考对象同样要求原始计数。

library(spacexr)
library(Seurat)

# ---- Build the scRNA-seq reference ----
# counts: genes x cells raw count matrix; cell_types: named factor of annotations
ref_counts <- GetAssayData(sc_ref, assay = "RNA", layer = "counts")
cell_types <- setNames(factor(sc_ref$cell_type), colnames(sc_ref))
nUMI_ref   <- colSums(ref_counts)

reference <- Reference(ref_counts, cell_types, nUMI_ref)
library(spacexr)
library(Seurat)

# ---- Build the spatial object ----
coords <- GetTissueCoordinates(brain)[, c("imagerow", "imagecol")]
sp_counts <- GetAssayData(brain, assay = "Spatial", layer = "counts")

puck <- SpatialRNA(coords, sp_counts, colSums(sp_counts))

# ---- Run deconvolution ----
# doublet_mode = "full" for Visium: a 55 um spot holds more than two cell types
rctd <- create.RCTD(puck, reference, max_cores = 4)
rctd <- run.RCTD(rctd, doublet_mode = "full")

# Weight matrix: spots x cell types, normalise rows to get proportions
weights <- rctd@results$weights
proportions <- sweep(weights, 1, rowSums(weights), "/")
head(round(proportions[, 1:5], 3))
#| label: fig-rctd-proportions
#| fig-cap: "RCTD 推断的细胞类型比例空间分布（stxBrain Visium 小鼠脑）。每个子图为一种细胞类型在各 Spot 中所占比例，绘制在真实组织坐标上。与 cell2location 的绝对丰度输出不同，此处为归一化后的相对比例，因此同一 Spot 中所有细胞类型的取值之和为 1，解读时需注意组成数据的此消彼长特性。"
library(Seurat)

# Carry proportions back onto the Seurat object for spatial plotting
for (ct in colnames(proportions)[1:3]) {
    brain[[paste0("prop_", ct)]] <- proportions[colnames(brain), ct]
}

SpatialFeaturePlot(brain, features = paste0("prop_", colnames(proportions)[1:3]), ncol = 3)

绝对丰度与相对比例不可混用： cell2location 默认输出绝对丰度（估计的细胞数量），RCTD 输出的权重经归一化后是相对比例。两者在解读上完全不同。设想一个 Spot 中免疫细胞数量不变、但肿瘤细胞大量增殖：绝对丰度会显示”免疫细胞不变、肿瘤细胞上升”，而相对比例会显示”免疫细胞比例下降”——后者极易被误读为免疫细胞减少。跨 Spot 或跨条件比较时，务必明确自己用的是哪一种，并在论文中写清楚。组成数据的这一陷阱与第 10 章微生物组分析中遇到的完全同源。

51 解卷积结果的验证

51.1 为什么验证比选方法更重要

解卷积的输出是一组数字，它总是存在、总是非负、总是能画成漂亮的空间热图——无论参考是否匹配、模型是否设定正确。因此不做验证就使用解卷积结果，是空间分析中最常见的严重错误。下面三类验证策略应当成为标准流程。

51.2 验证一：标志基因空间一致性

最直接也最有说服力的检验：若解卷积说某细胞类型富集在某个区域，那么该细胞类型的经典标志基因，其原始表达也应该在同一区域最高。这是一个完全独立于解卷积模型的证据——标志基因的表达是直接观测量，不经过任何反演。

#| label: fig-deconv-validation
#| fig-cap: "解卷积结果与标志基因表达的空间一致性核验（stxBrain Visium 小鼠脑）。上排为解卷积推断的两种细胞类型丰度空间分布，下排为对应细胞类型经典标志基因的原始表达空间分布。若解卷积结果可靠，同一列的上下两图应呈现高度重合的空间模式；二者若出现系统性错位，则提示参考图谱不匹配或模型设定有误。"
library(Seurat)
library(patchwork)

# Inferred abundance (top) versus raw marker expression (bottom)
p_top <- SpatialFeaturePlot(brain, features = c("prop_Astrocytes", "prop_Oligodendrocytes"), ncol = 2)
p_bot <- SpatialFeaturePlot(brain, features = c("Aqp4", "Mbp"), ncol = 2)

相关系数应当明显为正。若某细胞类型的推断丰度与其经典标志基因几乎不相关，该类型的解卷积结果就不可信。

51.3 验证二：模拟 Spot 基准

第二类验证是构造已知答案的测试。把 scRNA-seq 参考中的细胞按已知比例随机混合，人工合成”伪 Spot”，再用解卷积去还原——由于真实比例已知，可以直接量化误差。

library(Seurat)

# Build synthetic spots with known composition from the scRNA-seq reference
make_pseudo_spots <- function(sc_obj, n_spots = 200, cells_per_spot = 8, seed = 1) {
    set.seed(seed)
    counts <- GetAssayData(sc_obj, assay = "RNA", layer = "counts")
    types  <- as.character(sc_obj$cell_type)
    all_types <- sort(unique(types))

    spot_mat <- matrix(0, nrow = nrow(counts), ncol = n_spots,
                       dimnames = list(rownames(counts), paste0("pseudo", seq_len(n_spots))))
    truth <- matrix(0, nrow = n_spots, ncol = length(all_types),
                    dimnames = list(colnames(spot_mat), all_types))

    for (i in seq_len(n_spots)) {
        picked <- sample(ncol(counts), cells_per_spot)
        spot_mat[, i] <- Matrix::rowSums(counts[, picked, drop = FALSE])
        tab <- table(factor(types[picked], levels = all_types))
        truth[i, ] <- as.numeric(tab) / cells_per_spot
    }
    list(counts = spot_mat, truth = truth)
}

sim <- make_pseudo_spots(sc_ref, n_spots = 200, cells_per_spot = 8)
dim(sim$counts)
# Run the same deconvolution pipeline on the synthetic spots, then score it
# (estimated: spots x cell types, same ordering as sim$truth)
rmse <- sqrt(mean((estimated - sim$truth)^2))
cat("Overall RMSE:", round(rmse, 4), "\n")

# Per-cell-type accuracy: which types are recovered well, which are not?
per_type <- data.frame(
    cell_type = colnames(sim$truth),
    rmse = sqrt(colMeans((estimated - sim$truth)^2)),
    cor  = mapply(function(a, b) cor(a, b),
                  as.data.frame(estimated), as.data.frame(sim$truth))
)
per_type[order(per_type$rmse), ]

模拟基准的一个重要局限： 用同一份 scRNA-seq 参考既合成伪 Spot 又做解卷积，相当于让模型在”完美匹配的参考”下考试，结果必然偏乐观——它检验不出参考不匹配这一最主要的失效模式。更严格的做法是把参考随机拆成两半，一半合成伪 Spot、另一半作为解卷积参考；或者刻意从参考中删掉一种细胞类型，观察其信号被分摊到了哪里。后者尤其有价值，它能让你亲眼看到”缺失类型”的失效模式长什么样。

51.4 验证三：后验不确定性

cell2location 输出完整的后验分布，因而可以给出每个估计的可信区间。一个常被忽略的事实是：后验均值很高但区间也很宽的估计，其实是不可信的。绘图时应优先使用后验的 5% 分位数（q05）而非均值，这是一个保守的下界估计。

import numpy as np

# Posterior spread relative to the mean: a crude but useful uncertainty flag
q05 = adata_vis.obsm["q05_cell_abundance_w_sf"].values
q95 = adata_vis.obsm["q95_cell_abundance_w_sf"].values
mean = adata_vis.obsm["means_cell_abundance_w_sf"].values

relative_width = (q95 - q05) / (mean + 1e-6)
print("Median relative posterior width per cell type:")
print(np.round(np.median(relative_width, axis=0), 2))

51.5 解卷积失败的典型征象

最后，表 2 汇总了几类应当引起警觉的结果模式。它们不构成证明，但每一条都值得回头检查参考与参数。

黄金法则： 解卷积的输出永远存在，但它是否有意义完全取决于参考图谱——算法本身无法告诉你参考错了。因此解卷积的正确使用方式不是”跑完看结果”，而是”先用独立证据检验结果，再决定是否采信”。最有力的独立证据是标志基因的原始表达空间分布，因为它不经过任何反演、不依赖任何模型假设。一条实用的纪律是：凡是没有经过标志基因一致性核验的解卷积结果，不进入论文的结论部分。

52 方法总结与衔接说明

本专题把细胞解卷积拆解为三个层面。问题层面，它是一个带非负约束的混合模型反演，其难点不在求解而在模型设定——参考缺失细胞类型时算法不会报错，只会安静地给出错误答案。方法层面，从 RCTD、SPOTlight 的回归路线，到 cell2location 的层次贝叶斯路线，再到 CARD 引入空间平滑先验与 Tangram 的深度学习映射，各有取舍且不存在普遍最优；绝对丰度与相对比例两种输出的混用是常见的解读错误。验证层面，本专题给出了三条应成为标准流程的检验：标志基因空间一致性、模拟 Spot 定量基准、以及后验不确定性的正确使用。

解卷积产出的细胞类型丰度是本章后续分析的直接输入——专题 9.3 的空间细胞通讯与生态位分析，正是建立在”每个位置有哪些细胞类型”这一信息之上。而在此之前，专题 9.2 将回到空间域识别问题，看图神经网络如何用比 MRF 先验更灵活的方式利用空间邻接关系。

53 课后自测 (Post-Lesson Quiz)

  1. 请写出细胞解卷积的基本数学模型并说明其两个约束条件。为什么说它”看起来只是非负最小二乘，实际难点在别处”？

  2. 参考 scRNA-seq 图谱必须满足哪三项要求？其中哪一项无法从数据本身验证，只能依靠对组织生物学的了解？

  3. 为什么说”参考缺失细胞类型”是解卷积最危险的失效模式？它与一般的算法报错有何本质区别？

  4. cell2location 为什么把解卷积分为”学习签名”与”估计丰度”两个独立阶段？这种分解带来了什么实际好处？

  5. 绝对丰度与相对比例两种输出在解读上有何根本差异？请用”肿瘤细胞增殖而免疫细胞数量不变”这一情形说明误读的风险。

  6. RCTD 的 doublet_mode 假设每个 Spot 至多由两种主要细胞类型构成。为什么这一假设适合 Slide-seq 而通常不适合标准 Visium？

  7. 为什么说”标志基因空间一致性”是最有说服力的解卷积验证方法？它相比模型内部的拟合优度指标强在哪里？

  8. 某研究者用一份健康小鼠脑的 scRNA-seq 参考，对一批脑胶质瘤模型的 Visium 数据做了解卷积，结果显示肿瘤区域富集大量”星形胶质细胞”。请评估这一结论的可靠性，说明可能的问题，并给出验证与改进方案。

参考答案 (Reference Answers)

  1. 模型为 \(\mathbf{y}_s = \sum_{k} \beta_{sk}\mathbf{g}_k + \boldsymbol{\epsilon}_s\)，其中 \(\mathbf{y}_s\) 是 Spot 的观测表达向量、\(\mathbf{g}_k\) 是细胞类型 \(k\) 的签名、\(\beta_{sk}\) 是待求丰度。两个约束是非负性（\(\beta_{sk} \geq 0\)）与归一化（若输出相对比例则 \(\sum_k \beta_{sk} = 1\)）。难点在别处，是因为：（1）签名 \(\mathbf{g}_k\) 不是已知常量而是从另一批数据估计的，本身带误差与批次效应；（2）噪声不是高斯的，计数数据方差随均值增长，需泊松或负二项建模；（3）模型可能设定错误——参考缺少某类型时模型中不存在对应的 \(\mathbf{g}_k\)，算法仍会强行给出非负解。

  2. 三项要求：同源性（同物种、同组织，最好同发育阶段与病理状态）、完备性（覆盖目标组织中实际存在的所有细胞类型）、充分性（每种类型至少数十个细胞，通常 ≥ 50，以稳定估计签名）。其中完备性无法从数据本身验证——数据不会告诉你少了什么，只能依靠对目标组织生物学的了解来判断参考是否涵盖了所有应有的细胞类型。

  3. 因为它不会触发任何错误或警告。参考缺少某类型时，模型中不存在对应的签名向量，但算法仍会在现有的类型集合内求出一组满足非负约束的最优解，把缺失类型的信号分摊给签名最相似的已有类型。结果是一个数值合法、可以画成漂亮空间热图、看起来完全合理的错误答案。与一般算法报错的本质区别在于：报错会中断流程、提示使用者去检查；而这种失效是静默的，只有通过外部独立证据（如标志基因表达）才能发现。

  4. 因为第一阶段（学习签名）只依赖 scRNA 参考、与具体空间数据无关，第二阶段（估计丰度）固定签名再推断空间丰度。好处：（1）签名矩阵可复用于同组织的多个空间切片，避免每张切片重新训练参考，提高效率与跨切片一致性；（2）参考自身的批次效应在第一阶段就作为协变量消除，不会传递到空间推断；（3）两阶段解耦使得每一步的收敛可分别诊断，问题定位更容易。

  5. 绝对丰度估计的是细胞数量本身，相对比例估计的是各类型占该 Spot 的百分比，后者是组成数据，受”此消彼长”约束。在”肿瘤细胞大量增殖而免疫细胞数量不变”的情形下：绝对丰度会正确显示”免疫细胞不变、肿瘤细胞上升”；而相对比例会显示”免疫细胞比例下降”，极易被误读为免疫细胞减少甚至被排斥。跨 Spot 或跨条件比较时必须明确使用的是哪一种输出。这一陷阱与微生物组分析中的组成数据问题完全同源。

  6. 因为 doublet_mode 的假设是每个测量单元只覆盖极少数细胞。Slide-seq 的微珠直径约 10 µm，接近单细胞尺度，一个珠子通常只捕获一到两个细胞的 RNA，该假设基本成立。标准 Visium 的 Spot 直径 55 µm，通常涵盖 1–10 个细胞，强行假设至多两种主要类型会迫使模型丢弃真实存在的其他类型，产生系统性偏差。因此 Visium 上应使用 full 模式，允许每个 Spot 由任意多种类型混合构成。

  7. 因为标志基因的表达是直接观测量，完全不经过解卷积的反演过程，也不依赖解卷积模型的任何假设——它是一个真正独立的证据来源。相比之下，模型内部的拟合优度指标（如残差、似然）衡量的是”模型对数据拟合得好不好”，但一个设定错误的模型（如参考缺类型）同样可以拟合得很好：它把缺失类型的信号分摊出去后，重构误差可能依然很小。因此内部指标无法检出模型设定错误，而外部的标志基因证据可以。

  8. 这一结论高度可疑。核心问题是参考图谱与目标组织不匹配，违反了同源性要求：健康脑参考中不包含胶质瘤细胞这一类型，而胶质瘤细胞在转录特征上与星形胶质细胞最为接近（胶质瘤本就源自胶质细胞谱系）。因此解卷积无法识别肿瘤细胞，只能把它们的信号全部分摊给签名最相似的星形胶质细胞——“肿瘤区富集星形胶质细胞”很可能正是这一失效模式的表现，而非真实生物学。验证方案：（1）检查该区域的胶质瘤标志基因（如 EGFR 扩增相关基因、增殖标志 Mki67）的原始表达，若高表达则说明该区域是肿瘤细胞而非正常星形胶质细胞；（2）检查星形胶质细胞的经典标志（如 Aqp4、Gfap）在该区域的原始表达是否与推断丰度一致；（3）做”刻意删除类型”的模拟实验，观察删掉某类型后其信号被分摊到何处。改进方案：更换为含胶质瘤细胞的同病理状态 scRNA-seq 参考，或用该实验自身配套的肿瘤 scRNA-seq 数据构建参考，确保参考涵盖肿瘤细胞、反应性星形胶质细胞等所有实际存在的类型。
