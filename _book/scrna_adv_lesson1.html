37 专题概述

第 6 章的标准流程默认输入来自单一样本。然而真实研究几乎总是多样本的：多个供体、多个批次、多种处理条件。一旦合并多样本数据，技术批次效应便与生物学信号混杂。直接做 PCA 与聚类，往往得到”按样本分开”而非”按细胞类型分开”的结果。本专题首先讲解跨样本整合（Integration）如何在保留真实生物学差异的前提下消除批次效应，比较 Seurat 锚点、Harmony 与 scVI 三类方法，并用定量指标评估整合质量。随后转向多样本研究的两个核心统计问题：差异表达（Differential Expression，某细胞类型内部哪些基因变了）与差异丰度（Differential Abundance，哪些细胞类型或状态的比例变了）。贯穿全篇的一条统计原则是：以”细胞”为重复单位会严重低估方差、放大假阳性，正确的重复单位是”生物学样本”。本专题的每一个结论都在同一份真实数据上实测验证，读者可以逐段复现。

学习目标：理解批次效应与生物学信号的混杂机制，能用主成分回归诊断批次效应的来源；理解 MNN 锚点、Harmony 与 scVI 的算法原理及适用场景；掌握 Harmony 与 Seurat RPCA/CCA 整合的实操，能用 LISI 与”缺失细胞类型”压力测试评估批次混合度与过度整合风险；明确整合结果的使用边界；能用组内相关系数与设计效应定量解释伪重复，并通过零假设实验识别逐细胞检验的假阳性；掌握 muscat 拟bulk差异表达的配对设计与结果核验；理解组成数据约束，能运行 propeller 与 miloR 差异丰度检验，并区分”丰度改变”与”状态迁移”。

本专题的内容与时长分配见 表 1。

38 本专题使用的数据

38.1 一个用遗传变异”混样”的实验

本专题全程使用 Kang 等人发表的 IFN-β 刺激 PBMC 数据（Kang et al., 2018）。这项研究本身是一个方法学故事。作者想同时测量多名供体的单细胞转录组，又不愿为每名供体单独占用一个 10x 通道。那样做既昂贵，又会使”供体”与”通道”完全混杂。他们的办法是把 8 名系统性红斑狼疮患者的 PBMC 直接混在一起上样，测序后再依据 reads 中天然携带的 SNP 基因型，用自研的 demuxlet 算法把每个细胞”认领”回其供体（混样与遗传去卷积的原理参见专题 6.1）。混合细胞群被分为两份：一份用 IFN-β 刺激 6 小时（STIM），另一份不处理（CTRL），两份细胞分别上样、分别建库。demuxlet 的另一项收益是能识别来自不同供体的双细胞，数据中的 multiplets 列即为其判定结果。

muscData 中的 Kang18_8vs8 以 SingleCellExperiment 对象形式提供这份数据，包含 35,635 个基因 × 29,065 个液滴。元数据中有四列与本专题相关：ind（供体编号）、stim（条件）、cell（原作者注释的 8 种细胞类型）与 multiplets（demuxlet 判定）。

运行环境说明： 本专题的 R 代码依赖 Seurat（v5）、harmony、muscat、muscData、miloR、speckle、edgeR、DESeq2、presto、scater 与 lisi，均已在 R 4.5.2 / Seurat 5.5.1 / harmony 2.0.5 / muscat 1.24.0 / miloR 2.6.0 / speckle 1.10.0 环境下实测运行，正文所引数值均来自这次运行。Kang18_8vs8() 首次调用时需通过 ExperimentHub 联网下载约 39 MB 的数据，此后从本地缓存读取。除 scVI 与 scCODA 两段 Python 示意代码外，各步骤在普通笔记本上均可在一分钟内完成。

library(muscData)
library(SingleCellExperiment)
library(Seurat)

sce <- Kang18_8vs8()
dim(sce)                     # 35635 genes x 29065 droplets
table(sce$multiplets)        # demuxlet calls: singlet / doublet / ambs

# Keep demuxlet singlets that carry a cell-type label
sce <- sce[, sce$multiplets == "singlet" & !is.na(sce$cell)]
table(sce$cell, sce$stim)

# Build a Seurat object with gene symbols and the design columns
counts_mat <- counts(sce)
rownames(counts_mat) <- make.unique(as.character(rowData(sce)$SYMBOL))
md <- data.frame(ind  = factor(sce$ind),
                 stim = sce$stim,
                 cell = sce$cell,
                 row.names = colnames(sce))
md$sample <- paste(md$stim, md$ind, sep = "_")
kang <- CreateSeuratObject(counts_mat, meta.data = md,
                           min.cells = 3, min.features = 200)
kang

demuxlet 把 29,065 个液滴中的 24,679 个判为单细胞，3,169 个判为跨供体双细胞，1,217 个无法确定（ambs）。单细胞中另有 9 个缺少细胞类型标签，剔除后余 24,673 个细胞。构建 Seurat 对象时按 min.cells = 3, min.features = 200 再做一轮过滤，得到 15,701 个基因 × 24,562 个细胞（CTRL 12,261 个，STIM 12,301 个）。16 个”供体 × 条件”样本各含 461–2,738 个细胞。各细胞类型的细胞数见 表 2。

38.2 设计结构决定了能回答什么问题

这一设计的结构可以概括为一句话：供体与文库解耦，条件与文库耦合。由于 8 名供体的细胞在同一个文库中被一起处理，供体间差异不可能来自文库批次。这为后文以供体为重复单位的统计检验提供了干净的基础。每名供体同时出现在两种条件中，构成一个 8 对的配对设计，与第 4 章 airway 数据的 4 对细胞系配对设计同构（参见第 4 章）。反过来，CTRL 与 STIM 的细胞从未在同一个文库中出现，条件与文库批次完全混杂。

教学数据的一个诚实限定： 由于条件与文库完全对应，本数据中任何”STIM 相对 CTRL”的差异，在严格意义上都是”IFN-β 效应 + 文库批次效应”之和，无法从数据内部拆开。IFN-β 刺激引起的转录变化幅度极大，后文实测的干扰素刺激基因上调可达 \(2^6\)–\(2^8\) 倍，远超常见的文库间技术差异。因此本数据的主要结论在实践中可信，但对于效应量小的基因，这一混杂无法排除。设计自己的实验时，应让每个文库或批次同时包含各种条件的样本。

muscData::Kang18_8vs8() 与 Seurat 教程中常用的 ifnb（SeuratData::InstallData("ifnb")）来自同一实验。ifnb 是经 Seurat 团队过滤与重新注释的子集，只保留了条件标签，没有供体标签，因而无法用于任何需要生物学重复的分析。为使整合、差异表达与差异丰度三部分使用同一批细胞、结果可以前后对照，本专题统一使用 Kang18_8vs8。读者若按 Seurat 官方教程用 ifnb 练习整合部分，代码只需替换对象与列名，具体数值会因细胞过滤不同而略有差别。

39 跨样本整合与批次校正

39.1 批次效应的本质

批次效应（Batch Effect）指由非生物学因素引入的系统性技术变异，其来源包括供体个体差异、样本采集与处理时间、文库制备批次、测序批次以及 10x 化学版本差异。在 scRNA-seq 中，批次效应的典型表现是：同一种细胞类型来自不同批次时，在 PCA/UMAP 空间中分散为按批次聚集的多个团块，而非汇聚为一个统一的细胞类型簇。

批次效应的危险在于它与生物学信号混杂（confounded）。如果实验设计中每种处理条件只用一个批次处理，则批次与条件完全混淆，任何观测到的差异都无法归因于生物学还是技术。因此整合分析的前提是合理的实验设计。理想情况下，每个批次应包含各种条件的样本，即平衡设计。

一个著名的教训：物种还是测序批次？ 2014 年，小鼠 ENCODE 联盟的一项比较转录组研究报告：人与小鼠的多种组织样本首先按物种而非按组织聚类，提示同一物种不同组织之间的相似性高于不同物种的同一组织。Gilad 与 Mizrahi-Man 从原始 FASTQ 的读段标题中复原了测序仪与泳道信息，发现人与小鼠的样本基本分处不同的测序批次，物种与批次高度混杂。校正批次后，样本转而按组织聚类（Gilad & Mizrahi-Man, 2015）。这个例子说明，“按样本分开”的聚类结构本身不足以判断差异来自生物学还是技术，必须回到实验设计中查看二者是否混杂。

{{Wiki:Batch_effect}}

与 bulk RNA-seq 相比，单细胞批次效应还有一个特殊之处：它往往是细胞类型特异的。同一批次的技术偏差作用于单核细胞与作用于 T 细胞的方向和幅度可以不同。bulk 数据中常用的做法，是在设计矩阵中纳入批次变量，或用 ComBat / removeBatchEffect() 对每个基因减去批次均值（参见第 4 章）。这类做法隐含”所有样本受到同样偏移”的假设。单细胞数据的各批次细胞组成又往往不同。若直接对每个基因做全局线性校正，组成差异会被误当作批次偏移扣除。下文的三类整合方法都以某种方式在”局部”（细胞类型或细胞状态内部）估计批次效应，这是它们与 bulk 批次校正的根本区别。

39.2 先诊断，再整合

整合之前，应先回答两个问题：数据中是否存在需要校正的批次效应？如果存在，它来自哪个变量？主成分回归（PC regression）是最简单的诊断工具。它对每个主成分分别以候选变量（条件、供体、细胞类型）为自变量做线性回归，用决定系数 \(R^2\) 衡量该变量解释了这个主成分多少变异（Büttner et al., 2019）。

library(Seurat)

kang <- NormalizeData(kang)
kang <- FindVariableFeatures(kang, nfeatures = 2000)
kang <- ScaleData(kang)
kang <- RunPCA(kang, npcs = 30)

# PC regression: R^2 of each PC explained by condition / donor / cell type
pcs <- Embeddings(kang, "pca")
pc_r2 <- sapply(c("stim", "ind", "cell"), function(v)
    sapply(1:30, function(i) summary(lm(pcs[, i] ~ kang@meta.data[[v]]))$r.squared))
round(pc_r2[1:10, ], 3)

# Variance-weighted R^2 across all 30 PCs
pc_var <- apply(pcs, 2, var)
round(colSums(pc_r2 * pc_var) / sum(pc_var), 3)

结果呈现出清晰的分工（表 3）。PC1 几乎完全由细胞类型解释（\(R^2\) = 0.893），这是理想的生物学结构。PC2 却有 53.3% 的变异由条件解释，PC8 也有 25.7%。在全部 30 个主成分上按方差加权，细胞类型解释 49.6%，条件解释 8.1%，供体只解释 2.4%。这一诊断给出两个结论：第一，需要校正的主要变量是条件（即与条件耦合的文库），而非供体；第二，供体效应很弱，这正是同一文库混样设计的收益。

在本数据中，“批次”就是被研究的条件： 这里整合 stim 的目的，不是抹去 IFN-β 效应，而是让 CTRL 与 STIM 中的同一种细胞落到同一个坐标系里，以便统一聚类、统一注释，并在同一细胞类型内部比较两种条件。整合只作用于用于聚类的低维嵌入；差异表达仍然回到原始计数上做（见下文”整合结果的使用边界”）。这一用法要求读者始终清楚：校正后的嵌入中”看不到”条件差异，是设计使然，而不是条件差异不存在。

39.3 整合方法谱系

跨样本整合方法可大致分为三代，复杂度与计算代价递增：

  • 锚点法（Anchor-based，Seurat CCA/RPCA）：在样本对之间寻找互最近邻（Mutual Nearest Neighbors, MNN）作为锚点，再据此计算校正向量，将一个数据集对齐到另一个。RPCA 比 CCA 更快、更保守（不易过度整合），是大数据集的推荐选择。
  • Harmony：在 PCA 嵌入空间中迭代执行”软聚类 + 批次特异性线性校正”两步，直至批次在每个聚类内均匀混合（Korsunsky et al., 2019）。Harmony 不修改表达矩阵，只输出校正后的降维坐标，计算极快，适合数十万细胞规模的数据。
  • scVI（single-cell Variational Inference）：基于变分自编码器的深度生成模型，以负二项分布建模原始计数，将批次作为协变量编码进神经网络，输出批次校正后的隐变量空间与归一化表达（Lopez et al., 2018）。scVI 对复杂非线性批次效应的建模能力最强，但需要 Python 环境，大数据集通常还需要 GPU。

三类方法的权衡见 表 4。一项图谱级整合基准研究比较了十余种方法，发现在批次结构复杂的任务中，scANVI、Scanorama 与 scVI 等方法整体表现最好；Harmony 在批次结构较简单的任务上表现良好（Luecken et al., 2022）。没有一种方法在所有数据上都最优，因此整合后的定量评估不可省略。

39.4 三类方法的原理

39.4.1 互最近邻与锚点：Seurat CCA 与 RPCA

锚点法的思想源自 MNN 批次校正（Haghverdi et al., 2018）。设批次 1 中的细胞 \(a\) 与批次 2 中的细胞 \(b\)：若 \(b\) 位于 \(a\) 在批次 2 中的 \(k\) 个最近邻之内，同时 \(a\) 也位于 \(b\) 在批次 1 中的 \(k\) 个最近邻之内，则称二者构成一对 MNN。这一定义有一个关键性质：只有两个批次共有的细胞类型才可能形成 MNN。某批次独有的细胞类型，在另一批次中找不到”互相认可”的邻居。因此 MNN 对天然地给出了”哪些细胞是同一种状态”的配对证据，二者的表达差异向量就是该处批次效应的局部估计。

Seurat 在此基础上增加了三步（Stuart et al., 2019）。第一，先把两个数据集投影到一个共享空间再找 MNN。CCA 用典型相关分析寻找两数据集之间相关性最大的投影方向；RPCA 则把每个数据集投影到对方的 PCA 空间中，分别寻找近邻。第二，对每个锚点按其两端细胞近邻集合的重叠程度打分，思路与 SNN 权重相同（参见专题 6.3）。第三，对每个待校正细胞，用离它最近的若干锚点的校正向量加权平均，得到该细胞自己的校正量。CCA 擅长捕捉两数据集之间的共享相关结构，即便整体表达差异很大也能找到锚点，但也因此更容易把并不相同的细胞类型对齐。RPCA 要求锚点在双方各自的主成分空间中都成立，条件更严，因而更快、更保守。

{{Wiki:Nearest_neighbor_search}}

下面用一个可以手算的小例子，把”找近邻 → 互相认可 → 求校正量”三步逐一走一遍，再回到真实数据检验锚点的质量。

39.4.1.1 第一步：在共享空间中寻找跨批次近邻

设批次 1（CTRL）有 5 个细胞：\(a_1\)–\(a_3\) 为单核细胞，\(a_4\)、\(a_5\) 为 T 细胞。批次 2（STIM）有 6 个细胞：\(b_1\)–\(b_3\) 为单核细胞，\(b_4\)、\(b_5\) 为 T 细胞，\(b_6\) 是一种只在 STIM 中出现的新状态。批次 2 的单核细胞与 T 细胞相对批次 1 整体平移了约 \((0.6,\ 0.3)\)，并叠加了少量随机扰动，这就是待估计的批次效应。为便于手算，这里用二维坐标代替真实分析中 CCA 或 RPCA 给出的 30 维共享空间；降维的作用与第 6 章相同，每个细胞仍是一个点，只是坐标数变少了（参见专题 6.3）。各细胞的坐标见 表 5。

与 SNN 不同，MNN 只在另一个批次中找近邻。取 \(k = 2\)，每个细胞都在对方批次中列出距离自己最近的 2 个细胞，得到两份”跨批次近邻名单”（表 6）。

39.4.1.2 第二步：只保留”互相认可”的配对

单向近邻关系并不可靠。\(b_6\) 在批次 1 中最近的细胞是 \(a_5\) 与 \(a_4\)，但这只是因为批次 1 中根本没有与它相同的细胞，“最近”的也未必”相似”。MNN 的要求是双向的：只有当 \(a\) 出现在 \(b\) 的名单上，同时 \(b\) 也出现在 \(a\) 的名单上时，二者才构成一对 MNN。对照 表 6 逐行检查，共得到 8 对 MNN（表 7）。

这张表说明了三件事。第一，8 对 MNN 全部连接同一种细胞，没有一对跨越细胞类型。第二，\(b_6\) 没有任何 MNN：它名单上的 \(a_4\)、\(a_5\) 都把 \(b_4\)、\(b_5\) 排在它前面，不”认可”它。这正是”批次独有的细胞类型找不到 MNN”的具体体现。第三，\(a_1\) 虽然是正常的单核细胞，也没有 MNN：它看中的 \(b_1\)、\(b_2\) 更偏爱 \(a_2\)、\(a_3\)。在真实数据中，大多数细胞都不直接参与任何锚点，它们的校正量要从附近的锚点”借用”。

39.4.1.3 第三步：从配对向量到每个细胞的校正量

每对 MNN 的配对向量都是批次效应的一个局部估计，但单个估计的噪声很大。真实平移为 \((0.6,\ 0.3)\)，而 \(a_5\)–\(b_4\) 给出 \((0.0,\ 0.8)\)，\(a_4\)–\(b_5\) 给出 \((1.2,\ -0.1)\)。对多个配对取平均可以抵消噪声：4 对单核细胞的平均向量为 \((0.45,\ 0.20)\)，4 对 T 细胞的平均向量为 \((0.60,\ 0.35)\)，都已接近真实值。

真实方法不是对全体锚点取一个总平均，而是为每个待校正细胞 \(c\) 单独计算校正量：

\[ \Delta_c = \frac{\sum_{j} w_{cj}\, v_j}{\sum_{j} w_{cj}} \]

其中 \(v_j\) 为第 \(j\) 个锚点的配对向量，\(w_{cj}\) 为该锚点对细胞 \(c\) 的权重。距离 \(c\) 越近、锚点得分越高，权重越大；只有离 \(c\) 最近的若干个锚点参与计算。校正后的坐标为 \(c - \Delta_c\)。由于权重随距离衰减，单核细胞主要借用单核细胞锚点的向量，T 细胞主要借用 T 细胞锚点的向量。这就是锚点法能够处理”细胞类型特异的批次效应”的原因。

\(b_6\) 自己没有锚点，离它最近的是 T 细胞锚点，因此它大致按 T 细胞的平均向量平移：\((7.5,\ 3.0) - (0.60,\ 0.35) = (6.90,\ 2.65)\)。平移后它与最近的 \(a_5\) 仍相距约 2.3，作为一种独立状态保留了下来，没有被并入 T 细胞。

39.4.1.4 \(k\) 的选择：\(k = 3\) 时发生了什么

把 \(k\) 从 2 提高到 3，每份名单都多了一个候选，MNN 对从 8 对增加到 15 对（表 8）。

结果呈现出一个典型的权衡。对单核细胞而言，更大的 \(k\) 带来更多正确配对，平均向量恰好等于真实平移 \((0.6,\ 0.3)\)。对 T 细胞而言，批次 2 只有 2 个 T 细胞，\(k = 3\) 迫使 \(a_4\)、\(a_5\) 把第三个名额给了 \(b_6\)。\(b_6\) 的名单上也恰好有 \(a_4\)、\(a_5\)，于是出现了两对错误的 MNN：\(a_4\)–\(b_6\) 与 \(a_5\)–\(b_6\)，配对向量分别为 \((2.5,\ -2.0)\) 与 \((2.0,\ -1.5)\)。

这两对错误配对造成两个后果。第一，T 细胞端全部 6 对的平均向量被拉偏到 \((1.15,\ -0.35)\)，与真实值相去甚远。第二，更严重的是 \(b_6\) 获得了自己的锚点，按其平均向量 \((2.25,\ -1.75)\) 校正后落在 \((5.25,\ 4.75)\)，恰好位于 \(a_4\) 与 \(a_5\) 之间。一种只存在于 STIM 中的新状态就这样被”整合”进了 T 细胞，这正是过度整合的机制。规律是：当 \(k\) 超过某种共享细胞类型在另一批次中的细胞数时，多出的名额只能分给其他类型，错误配对便随之产生。Seurat 寻找锚点时默认 k.anchor = 5，正是为了让每个细胞只与极少数最可信的伙伴配对。

39.4.1.5 Seurat 的过滤与打分

真实数据比上例复杂得多，Seurat 因此在 MNN 之后又加了两道关卡（Stuart et al., 2019）。第一道是过滤：锚点是在低维共享空间中找到的，Seurat 回到由锚点特征基因构成的高维表达空间复核：若锚点一端的细胞不在另一端细胞于对方数据集中的前 200 个近邻之内（k.filter = 200），该锚点即被剔除。第二道是打分：对每个锚点，Seurat 统计其两端细胞在两个数据集中各自 30 个近邻（k.score = 30）的重叠程度，再把得分按分位数缩放到 0–1 之间。得分高，说明两个细胞不仅彼此相邻，各自所处的”邻里”也相互对应。这一思路与 SNN 的 Jaccard 权重相同（参见专题 6.3）。最后，在计算每个细胞的校正量时，只使用离它最近的 100 个锚点（IntegrateData() 的 k.weight = 100）。

跨类型的锚点并非随机分布。以 CCA 为例，CD8 T 细胞的锚点有 17.7% 连到 NK 细胞、12.8% 连到 CD4 T 细胞；树突状细胞的锚点有 12.6% 连到 CD14+ 单核细胞；CD14+ 单核细胞与 FCGR3A+ 单核细胞之间也互有约 8% 的锚点。这些都是转录组上连续过渡的相邻类型：CD8 效应 T 细胞与 NK 细胞共享细胞毒性程序，两类单核细胞之间存在中间状态。因此，这类”错配”相当一部分反映的是注释边界本身的模糊，而不是整合算法把截然不同的细胞对齐了。与之形成对照的是，B 细胞、CD4 T 细胞与 NK 细胞的锚点同类比例都在 92% 以上。

还有一点值得说明。锚点得分并不能把这些跨类型锚点筛出来：把 CCA 锚点按得分分为五档，各档的同类比例都在 86%–92% 之间，没有随得分升高而上升。这与专题 6.3 中 SNN 权重能够预示近邻关系可重复性的结果不同。原因在于，跨类型锚点集中在相邻类型的过渡区域，那里的细胞在近邻结构上本就彼此交织，“邻里对应”的程度与同类配对相当。锚点得分衡量的是局部结构是否一致，而不是细胞类型标签是否相同。

39.4.2 Harmony：在嵌入空间中迭代”聚类—校正”

Harmony 不处理基因表达矩阵，而是直接在 PCA 嵌入上工作。它交替执行两步，直至收敛。

第一步是最大多样性聚类（maximum diversity clustering）。Harmony 对细胞做软 \(k\)-means 聚类，每个细胞 \(i\) 以概率 \(R_{ki}\) 隶属于聚类 \(k\)。与普通软聚类不同，其目标函数额外加入一个多样性惩罚。若某聚类中批次 \(b\) 的观测细胞数 \(O_{kb}\) 多于按全局比例应有的期望数 \(E_{kb}\)，则来自批次 \(b\) 的细胞被分配到该聚类的概率会受到惩罚，大致满足

\[ R_{ki} \propto \exp\!\left(-\frac{\lVert z_i - y_k \rVert^2}{\sigma}\right)\left(\frac{E_{k b_i}}{O_{k b_i}}\right)^{\theta} \]

其中 \(z_i\) 为细胞的嵌入坐标，\(y_k\) 为聚类中心，\(\sigma\) 控制软聚类的”软”度，\(\theta\) 控制多样性惩罚的强度。\(\theta = 0\) 时退化为普通软聚类；\(\theta\) 越大，聚类越被迫在各批次间均匀混合。

第二步是混合专家线性校正（mixture of experts correction）。对每个聚类 \(k\)，以 \(R_{ki}\) 为权重，用带岭惩罚 \(\lambda\) 的线性模型估计该聚类内各批次的平均偏移 \(W_k\)。随后从每个细胞的坐标中减去其所属各聚类偏移的加权和：

\[ \hat z_i = z_i - \sum_k R_{ki}\, W_k^{\top}\phi_i \]

\(\phi_i\) 为细胞 \(i\) 的批次指示向量（不含截距）。由于偏移是按聚类分别估计的，Harmony 允许不同细胞类型具有不同方向与大小的批次效应。这正是它优于”整体减去批次均值”一类全局线性校正的原因。

39.4.3 scVI：把批次写进生成模型

scVI 把整合问题改写为概率建模问题。它假设每个细胞 \(n\) 的原始计数由一个低维隐变量 \(z_n\) 与批次标签 \(s_n\) 共同生成：

\[ z_n \sim \mathcal{N}(0, I), \qquad \rho_n = f_w(z_n, s_n), \qquad x_{ng} \sim \mathrm{NB}\!\left(\ell_n \rho_{ng},\ \theta_g\right) \]

其中 \(f_w\) 是解码器神经网络，输出经 softmax 归一化的基因表达比例 \(\rho_n\)；\(\ell_n\) 为文库大小；\(\theta_g\) 为基因特异的离散度参数（负二项模型的含义参见第 4 章）。编码器网络 \(q(z_n \mid x_n, s_n)\) 近似隐变量的后验分布。两者通过最大化证据下界（ELBO）联合训练，这一结构即变分自编码器（Variational Autoencoder, VAE）。

{{Wiki:Variational_autoencoder}}

批次校正的关键在于：解码器已经”知道”批次 \(s_n\)，能够自行解释由批次引起的表达差异，于是隐变量 \(z_n\) 无需、也不应再编码批次信息。训练完成后，\(z_n\) 即为批次校正后的低维表示，可直接用于构建近邻图、聚类与 UMAP。scVI 还能在解码时把所有细胞的批次标签统一设为同一个值，生成”假如都在同一批次中测量”的归一化表达。与 Harmony 相比，scVI 直接对原始计数建模，能捕捉非线性的批次效应，并自然扩展到半监督注释（scANVI，参见专题 6.3）与参考映射。代价是需要 Python 与 PyTorch 环境，训练耗时较长，且结果受随机初始化与训练轮数影响。

下一节的定量评估显示，按供体整合后，条件的局部混合度与未校正时完全相同，16 个聚类中仍有 10 个超过 90% 的细胞来自同一条件。原因在于主成分回归早已表明：供体效应很弱，条件才是主导变异。Harmony 只会消除被告知的变量。若指定的变量本来就混合良好，算法几乎无事可做，真正的批次结构则原封不动地保留下来。选择整合变量之前，先做诊断。

多个批次变量与 theta 参数： 当批次结构包含多层（如测序批次与供体），可向 group.by.vars 传入多个变量，并用等长的 theta 向量分别设置惩罚强度。theta 的默认值为 2。在本数据上把 theta 提高到 8，条件混合度几乎不变（iLISI 1.644 → 1.646），说明默认值已足以对齐两种条件；盲目加大 theta 并不会带来更好的整合，反而增加过度整合的风险。

39.8 整合质量评估

39.8.1 LISI：用局部邻域衡量混合与分离

整合的目标是在”混合批次”与”保留生物学结构”之间取得平衡。两类指标分别量化这两个目标。局部逆辛普森指数（Local Inverse Simpson’s Index, LISI）是其中最常用的一种（Korsunsky et al., 2019）。对每个细胞，LISI 先在嵌入空间中取其近邻（以高斯核按距离加权），统计近邻中各类别的比例 \(p_1, \dots, p_B\)，再计算

\[ \mathrm{LISI} = \frac{1}{\sum_{b=1}^{B} p_b^2} \]

LISI 可理解为”该细胞邻域中有效的类别数”。若邻域全部来自同一类别，LISI = 1；若 \(B\) 个类别等比例混合，LISI = \(B\)。同一公式对不同标签有不同解读：

  • iLISI（integration LISI）：以批次为标签，衡量批次混合度，越高越好，上限为批次数。kBET 是另一种基于卡方检验的批次混合度指标，思路相近（Büttner et al., 2019）。
  • cLISI（cell-type LISI）：以细胞类型为标签，衡量生物学保真度，越接近 1 越好（邻域内细胞类型纯净）。

二者构成此消彼长的权衡：过度整合（over-correction）会人为合并不同的细胞类型，表现为 iLISI 升高但 cLISI 恶化。

安装说明： lisi 包需从 GitHub 安装：remotes::install_github("immunogenomics/lisi")。在较新的 R 与 RcppArmadillo 组合下，其 src/Makevars 中的 CXX_STD = CXX11 一行会导致编译失败。解决办法是下载源码，删除该行后用 R CMD INSTALL 安装。macOS 上若未安装 gfortran，还需从同一文件的 PKG_LIBS 中删去 $(FLIBS)。

# Adjusted Rand index between two labelings
ari <- function(a, b) {
    tab <- table(a, b); n <- sum(tab)
    s  <- sum(choose(tab, 2))
    sa <- sum(choose(rowSums(tab), 2)); sb <- sum(choose(colSums(tab), 2))
    e  <- sa * sb / choose(n, 2)
    (s - e) / ((sa + sb) / 2 - e)
}

      ARI_cell       = round(ari(obj$seurat_clusters, obj$cell), 3),
      condition_pure = sum(apply(cond_share, 1, max) > 0.9))
}

39.8.2 压力测试：当某种细胞只存在于一个批次

上述数据中，两种条件包含完全相同的细胞类型，是整合最容易的情形。真实研究中，某种细胞可能只出现在部分批次，例如疾病特异的细胞状态。此时整合算法面临真正的考验：它会不会强行给这些”没有对应物”的细胞找一个错误的伙伴？一个简单而有效的压力测试是人为删除某批次中的一种细胞类型，再看另一批次中的同类细胞是否被拉向错误的细胞类型。

判断是否过度整合的实操方法： 整合后检查已知标志基因的表达是否仍在预期的细胞类型中特异分布。例如，若整合后 CD3D（T 细胞）与 LYZ（单核细胞）的表达边界变得模糊，或两个本应分开的细胞类型簇被强行合并，则提示过度整合。对生物学差异较大的样本，优先选用更保守的 RPCA 而非 CCA。压力测试与标志基因检查互为补充：前者检验算法在”无对应物”时的行为，后者检验真实数据上的生物学结构是否保留。

39.9 整合结果的使用边界

整合产出的是一个用于”找邻居”的坐标系，而不是一份新的表达数据。这一区分决定了整合结果能做什么、不能做什么。

校正后的嵌入（Harmony、RPCA/CCA 的降维输出、scVI 隐变量）适用于构建近邻图、聚类、UMAP 可视化、细胞类型注释与标签传递，以及下文 miloR 差异丰度分析所需的 KNN 图。它们不适用于差异表达：Harmony 从不修改表达矩阵，整合前后 data layer 中的数值完全相同。在本数据中，CD14+ 单核细胞的 ISG15 对数归一化表达均值在 CTRL 中为 0.69，在 STIM 中为 6.09；IFI6 分别为 0.53 与 3.31。整合后这些数值不变，条件效应完整保留在表达矩阵中，留待差异表达分析检验。

# Harmony only changes the embedding: expression values are untouched
mono_cells <- colnames(kang)[kang$cell == "CD14+ Monocytes"]
isg <- FetchData(kang, vars = c("ISG15", "IFI6", "stim"),
                 cells = mono_cells, layer = "data")
aggregate(cbind(ISG15, IFI6) ~ stim, data = isg, FUN = mean)

不要在”校正后的表达值”上做差异表达： Seurat v4 IntegrateData() 生成的 integrated assay、removeBatchEffect() 的输出与 scVI 的归一化表达，都是经过模型变换的数值。它们之间不再相互独立，也不再服从计数分布；校正过程还可能把条件差异部分地当作批次效应扣除。用这些数值做差异检验，P 值没有意义。正确的做法是：用校正后的嵌入确定细胞身份，再回到原始计数，把批次或供体作为协变量写进差异表达模型（参见第 4 章”在设计矩阵中包含批次变量”）。

40 多样本差异表达：拟bulk方法

40.1 伪重复问题

获得整合后的细胞图谱并完成注释后，一个常见目标是检验某细胞类型在两种条件间的差异表达基因。直觉上似乎可以直接用 FindMarkers() 的 Wilcoxon 检验，把”细胞”当作样本逐个比较。这是单细胞差异分析中最常见的统计错误。

问题在于伪重复（pseudo-replication）：同一供体的数千个细胞并非相互独立的观测，它们共享该供体的遗传背景、处理批次与技术状态。把细胞当作独立重复，等于把样本量从”几个供体”虚增到”几千个细胞”，导致方差被严重低估、P 值极度偏小。多项基准研究表明，逐细胞检验会产生大量假阳性，其”显著基因”很多只反映个别供体的特异性，而非可重复的条件效应（Squair et al., 2021）。

“伪重复”一词的来历： 这个术语并非源自基因组学，而是来自生态学。1984 年，生态学家 Stuart Hurlbert 在《Ecological Monographs》上发表了一篇关于野外实验设计的长文，系统梳理了当时生态学文献中的统计错误。他把”处理只施加于一个实验单元，却把该单元内的多次测量当作独立重复”的做法命名为伪重复。例如，只在一个池塘里施肥，却把从该池塘采集的十份水样当作十个重复。三十多年后，单细胞研究以几乎相同的形式重现了这个错误：一个供体就是一个”池塘”，它的数千个细胞就是同一池塘里的水样。

{{Wiki:Pseudoreplication}}

黄金法则： 多样本差异表达的统计重复单位是生物学样本（供体），而不是细胞。任何把成千上万个细胞当作独立重复的检验，都会因伪重复而产生不可重复的假阳性。正确的做法是先将细胞聚合为拟bulk，再以样本为单位做检验。

40.2 量化伪重复：组内相关与设计效应

伪重复的危害可以精确地量化。设某基因在供体 \(j\) 的细胞 \(i\) 中的表达为 \(y_{ij}\)，其总方差 \(\sigma^2\) 可分解为供体间方差 \(\sigma_b^2\) 与供体内（细胞间）方差 \(\sigma_w^2\) 两部分。二者之比定义为组内相关系数（Intraclass Correlation Coefficient, ICC）：

\[ \rho = \frac{\sigma_b^2}{\sigma_b^2 + \sigma_w^2} \]

\(\rho\) 衡量同一供体的两个细胞彼此”有多像”。若每名供体贡献 \(m\) 个细胞、共 \(n\) 名供体，则组均值的方差为

\[ \mathrm{Var}(\bar y) = \frac{\sigma^2}{nm}\,\bigl[1 + (m-1)\rho\bigr] \]

方括号内的因子称为设计效应（design effect）。它表明，\(nm\) 个细胞所携带的信息量只相当于 \(nm / [1+(m-1)\rho]\) 个独立观测。当 \(m\) 很大时，有效样本量趋近于 \(n/\rho\)：无论每名供体测多少个细胞，信息量的上限都由供体数决定。逐细胞检验却假设 \(\rho = 0\)，即把设计效应当作 1。

{{Wiki:Design_effect}}

这个公式的威力在于：即便 \(\rho\) 很小，只要 \(m\) 足够大，设计效应依然可观。下面在 CTRL 条件的 CD14+ 单核细胞中，用单因素方差分析的矩估计计算各高变基因的 ICC：

ctrl_mono <- subset(kang, subset = stim == "ctrl" & cell == "CD14+ Monocytes")
logn_m <- LayerData(ctrl_mono, layer = "data")
counts_m <- LayerData(ctrl_mono, layer = "counts")
keep_g <- rowMeans(counts_m > 0) >= 0.10          # genes detected in >= 10% of cells
hvg <- intersect(VariableFeatures(kang), rownames(logn_m)[keep_g])

# One-way ANOVA estimator of the donor intraclass correlation
icc <- sapply(hvg, function(g) {
    x <- logn_m[g, ]; f <- droplevels(ctrl_mono$ind)
    a <- anova(lm(x ~ f))
    msb <- a$`Mean Sq`[1]; msw <- a$`Mean Sq`[2]
    n0 <- (length(x) - sum(table(f)^2) / length(x)) / (nlevels(f) - 1)
    sb2 <- max((msb - msw) / n0, 0)
    sb2 / (sb2 + msw)
})
quantile(icc, c(0.25, 0.5, 0.75, 0.9))
m_bar <- mean(table(ctrl_mono$ind))
1 + (m_bar - 1) * median(icc)                     # design effect at the median ICC

在 2,770 个 CTRL CD14+ 单核细胞中（各供体 112–779 个，平均 346 个），329 个检测率不低于 10% 的高变基因的 ICC 中位数仅为 0.017，四分位范围为 0.007–0.035。也就是说，对典型基因而言，供体差异只占细胞间总变异的不到 2%。然而代入设计效应公式，\(1 + (346 - 1) \times 0.017 \approx 6.8\)：这 2,770 个细胞所携带的信息只相当于约 400 个独立观测。逐细胞检验却把它们当作 2,770 个，标准误被低估约 \(\sqrt{6.8} \approx 2.6\) 倍。对 ICC 位于第 90 百分位（0.058）的基因，设计效应超过 20。

40.3 一个零假设实验：没有差异时会找到多少差异基因

设计效应给出了理论预期，零假设实验则给出直接证据。思路很简单：只取 CTRL 条件的细胞，把 8 名供体随机分成两组各 4 人，再比较这两组。由于所有细胞都未经处理，两组之间不存在任何真实的条件效应，任何”显著”基因都是假阳性。8 名供体分成两个 4 人组共有 \(\binom{8}{4}/2 = 35\) 种不同分法，可以全部枚举。

library(presto)

40.4 拟bulk聚合的逻辑

拟bulk（Pseudobulk）方法的思想是：对每个样本、每种细胞类型，将其所有细胞的原始计数逐基因相加，得到一个”伪批量”表达谱。这样，一个 8 供体 × 2 条件的实验，对某细胞类型就得到 16 个拟bulk样本，恰好回到了经典 bulk RNA-seq 的统计框架，可直接套用 DESeq2/edgeR 的负二项模型（参见第 4 章）。

聚合时求和而非求平均，有两层原因。第一，求和保留了计数的整数性质与总测序深度，使负二项分布的均值-方差关系依然成立，DESeq2 的大小因子与离散度估计仍然适用。第二，不同样本中同一细胞类型的细胞数不同，求和后这一差异被吸收进文库大小，由归一化步骤处理；求平均则会丢失”该均值基于多少个细胞”的信息，使细胞多的样本与细胞少的样本被同等看待。聚合后样本间的变异自然反映了真实的生物学重复变异，从而给出校准良好的 P 值。

40.5 muscat 拟bulk差异分析实操

muscat 把”按样本 × 细胞类型聚合，再逐细胞类型做 bulk 差异检验”这一流程封装为几个函数（Crowell et al., 2020）。它要求三个元数据列：cluster_id（细胞类型）、sample_id（样本）与 group_id（条件），由 prepSCE() 统一命名。

sample_id 必须是”供体 × 条件”，而不是供体： 在配对设计中，每名供体同时贡献 CTRL 与 STIM 两个样本。若把 sid 直接设为供体编号 ind，则一个”样本”会同时包含两种条件的细胞，聚合后条件信息丢失。正确做法是先拼接出 stim + ind 形式的样本编号，得到 16 个样本，再把供体作为区组因子单独写进设计矩阵。

40.8 逐细胞检验与拟bulk的正面比较

回到本节开头的问题：在真实存在强烈条件效应的数据上，逐细胞 Wilcoxon 检验与拟bulk的结论有多大差别？在 CD14+ 单核细胞中，对检测率不低于 10% 的 1,695 个基因做 STIM 相对 CTRL 的逐细胞 Wilcoxon 检验，1,486 个（87.7%）达到 FDR < 0.05。其中 76 个基因的 P 值小到超出双精度浮点数的表示范围，被直接记为 0。在同一组 1,695 个基因上，配对拟bulk edgeR 判定 1,320 个显著。有 265 个基因只被 Wilcoxon 检验判为显著。

这一比较与零假设实验相互印证。当条件效应强大时，两种方法会共同检出大部分真实信号，差别集中在效应量较小、供体间不一致的基因上。正是这些基因构成了逐细胞检验多出来的部分。零假设实验已经表明，逐细胞检验在没有任何条件效应时也会报告数百个基因。因此，这 265 个”Wilcoxon 独有”基因中有多少是真实信号，无法从逐细胞检验本身得到回答。逐细胞检验的 P 值也失去了概率意义：一个 \(10^{-300}\) 的 P 值并不表示这一结果比 \(10^{-15}\) 可靠 \(10^{285}\) 倍，它只是细胞数被当作样本量的产物。

细胞数过少的细胞类型不可靠： 当某细胞类型在某些样本中细胞数很少时，其拟bulk计数受少数细胞主导，离散度估计不稳定。本数据中巨核细胞最少的样本只有 4 个细胞，在配对设计下已无法分析。实践中应在聚合前检查”细胞类型 × 样本”的细胞数表，通过 min_cells 参数剔除细胞数过低的样本，并在结果中标注受影响的细胞类型。不应为了”凑出结果”而把相近的细胞类型临时合并，那会改变所检验的生物学问题。

40.9 混合模型：另一条可行路径

拟bulk并非处理伪重复的唯一方法。另一条路径是保留细胞级数据，在模型中显式加入供体随机效应：

\[ y_{ij} = \beta_0 + \beta_1 \cdot \mathrm{condition}_j + u_j + \varepsilon_{ij},\qquad u_j \sim \mathcal{N}(0, \sigma_b^2) \]

随机效应 \(u_j\) 吸收了同一供体细胞的共享偏移，使条件效应 \(\beta_1\) 的标准误正确反映供体层面的变异。Zimmerman 等人用模拟与真实数据比较了两条路径，认为带供体随机效应的广义线性混合模型（GLMM）能够纠正伪重复偏差，而拟bulk方法在部分场景下过于保守（Zimmerman et al., 2021）。Murphy 与 Skene 随后用同时衡量假阳性与假阴性的平衡指标重新评估，得出拟bulk方法整体表现更优的相反结论（Murphy & Skene, 2022）。这场争论尚无定论，但双方在一点上完全一致：以细胞为独立重复的检验是错误的。

在实践中，两条路径的取舍主要取决于计算成本与研究问题（表 13）。muscat 的 mmDS() 函数提供了混合模型的实现（如 method = "dream"），可与 pbDS() 的结果相互对照。

FindMarkers() 仍有它的正当用途： 逐细胞检验并非一无是处。在单一样本中为聚类寻找标志基因时，研究问题是”这群细胞与其他细胞有何不同”，并不涉及推广到新供体，逐细胞检验作为排序工具是合理的（其双重浸入问题参见专题 6.3）。错误只发生在把它用于”条件 A 与条件 B 之间”这类需要以供体为单位推广的问题时。判断标准是：结论是关于这些细胞的，还是关于这类样本的。

41 差异丰度分析

41.1 组成数据的挑战

差异表达回答”基因变了多少”，差异丰度（Differential Abundance, DA）则回答”细胞类型的比例变了多少”，例如刺激后某个激活态细胞群是否扩张。最朴素的做法是统计每个样本中各细胞类型的比例，再做组间 t 检验。但这种做法有两个缺陷。

第一，依赖离散聚类。预先定义的细胞类型聚类可能掩盖聚类内部的连续状态变化。真正发生扩张的或许只是某聚类中的一个亚状态，而非整个聚类。

第二，组成数据的约束。各细胞类型比例之和恒为 1，因此一个类型的真实扩张会机械地压低其他所有类型的比例，产生虚假的”减少”信号。设某样本含 T 细胞 600 个、B 细胞 200 个、单核细胞 200 个；处理后单核细胞绝对数量翻倍为 400 个，T 与 B 细胞不变。比例随之从 60% / 20% / 20% 变为 50% / 16.7% / 33.3%。T 与 B 细胞的绝对数量没有任何变化，比例却分别下降了 10 与 3.3 个百分点。这种”此消彼长”是组成数据（compositional data）分析的核心难题：比例数据落在一个总和恒定的单纯形上（图 1），不能直接套用欧氏空间的统计方法。单细胞测序只能捕获每个样本的一部分细胞，观测到的天然就是比例而非绝对数量，因此这一约束无法通过增加测序深度来消除。

41.2 细胞类型层面：propeller 比例检验

在已定义的细胞类型层面，propeller 是一种简单而稳健的检验方法（Phipson et al., 2022）。它先计算每个样本中各细胞类型的比例，再做 logit 或反正弦平方根变换以稳定方差，最后用 limma 的经验贝叶斯线性模型逐细胞类型检验。由于以样本比例为观测值，propeller 天然以样本为重复单位，并能通过设计矩阵纳入配对结构：

library(speckle)
library(limma)

md <- kang@meta.data

# Per-sample cell-type proportions (%)
round(100 * prop.table(table(md$sample, md$cell), 1), 1)

# (a) Unpaired comparison
propeller(clusters = md$cell, sample = md$sample, group = md$stim,
          transform = "logit")

# (b) Paired comparison: donor as a blocking factor in the design

smp   <- colnames(props$TransformedProps)
grp   <- factor(sub("_.*", "", smp))
donor <- factor(sub(".*_", "", smp))

propeller.ttest(props, design = des,
                contrasts = c(1, -1, rep(0, ncol(des) - 2)),
                robust = TRUE, trend = FALSE, sort = TRUE)

各样本的细胞组成首先显示出巨大的供体差异。CD8 T 细胞的比例在多数样本中为 2%–9%，供体 1016 却高达 31.1%（CTRL）与 29.9%（STIM）。CD4 T 细胞的比例也在 21.6%–58.3% 之间变动。相比之下，同一供体两种条件之间的差别很小。非配对检验中，8 种细胞类型的 FDR 均大于 0.8，没有任何类型达到显著。配对检验消除了供体间差异后，CD8 T 细胞的比例从 8.6% 降至 7.7%，FDR = 0.035，达到显著；NK 细胞从 7.2% 升至 8.5%，未校正 P = 0.036，但 FDR = 0.14。

这个”显著”结果需要谨慎解读。体外刺激只有 6 小时，细胞几乎不可能在如此短的时间内增殖或分化，真实细胞数量发生改变的可能性很低。更可能的解释有两种：一是刺激改变了不同细胞类型的存活率或被捕获的效率；二是干扰素诱导的转录变化使部分细胞跨过了注释边界。CD8 T 细胞的下降与 NK 细胞的上升恰好方向相反、幅度相近，而二者共享多种细胞毒性基因，后一种解释尤其值得怀疑。统计检验只能回答”观测到的比例是否不同”，无法回答”为什么不同”。比例差异的生物学解读，必须结合实验时间尺度与注释的稳定性。

41.3 scCODA：带参考细胞类型的贝叶斯组成模型

propeller 逐细胞类型独立检验，并未显式处理组成约束。scCODA 则用贝叶斯狄利克雷-多项式模型对全部细胞类型的计数联合建模（Büttner et al., 2021）。它要求指定一个”参考细胞类型”，假设该类型的绝对丰度在条件间不变，其他类型的变化都相对于它来表达，以此锚定组成约束。参考类型的选择会影响结论，应选择在所有样本中都存在、且生物学上预期不受处理影响的类型。

41.4 miloR 邻域差异丰度检验

miloR 通过两项设计绕开了离散聚类与组成约束的局限（Dann et al., 2022）。其一，它不依赖离散聚类，而是在 KNN 图上定义大量相互重叠的邻域（neighborhood），每个邻域是一个代表细胞及其近邻。miloR 在邻域这一精细尺度上检验丰度变化，从而捕捉连续状态的扩张或收缩。其二，它用负二项广义线性模型（NB-GLM）对每个邻域内各样本的细胞计数建模，以样本为重复单位，并用加权的空间 FDR（SpatialFDR）校正邻域间的重叠与多重检验。

library(SingleCellExperiment)

41.4.1 嵌入空间的选择决定了 DA 检验在问什么

miloR 的邻域建立在 KNN 图之上，而 KNN 图取决于所用的嵌入。在本数据中分别用未校正 PCA 与 Harmony 嵌入运行同一流程，结论截然不同（表 14）。

在未校正嵌入中，94.4% 的邻域超过 90% 的细胞来自同一条件，因此几乎每个邻域都”显著”。这些结果的含义是”STIM 细胞与 CTRL 细胞位于表达空间的不同位置”，它描述的是表达状态的改变，而非丰度的改变。把它报告为差异丰度，就是把差异表达信号重复计算了一遍。在 Harmony 嵌入中，两种条件的同类细胞被对齐，条件纯邻域降至 10.0%，显著邻域的比例也降至一半左右。邻域代表细胞的抽样带有随机性，重复运行时邻域数与显著邻域数会小幅波动（另一次独立运行得到 937 个邻域、459 个显著，其中上升 256 个、下降 203 个），但显著比例与方向分布基本不变。

DA 分析的嵌入选择没有中性答案： 用未校正嵌入，DA 会把表达状态的改变误报为丰度改变；用整合后的嵌入，若整合过度，真正只存在于某一条件的新细胞状态可能被并入已有状态，导致真实的 DA 被抹去。实践中应以整合嵌入为主，同时检查显著邻域在细胞类型内部是单向还是双向分布，并与 propeller 等细胞类型层面的结果对照。若研究的核心问题是”刺激是否诱导出新的细胞状态”，应在未整合的数据中单独检查该状态是否只存在于一种条件。

差异表达与差异丰度的互补解读： 一个条件效应可能表现为差异丰度（某细胞类型扩张）、差异表达（某细胞类型内部基因上调），或两者兼有。本数据给出了一个清晰的例子：IFN-β 刺激 6 小时后，各细胞类型内部有数百至数千个基因显著变化（DE），细胞类型层面的组成却几乎不变（DA）。邻域层面的大量显著结果，主要是 DE 在嵌入空间中留下的残余，而不是独立的丰度信号。完整的多样本分析应同时报告这两个层面，并说明二者如何相互印证。

42 方法总结与衔接说明

本专题确立了多样本单细胞分析的统计基石，并在同一份数据上逐一验证。第一，先诊断，再整合：主成分回归显示 Kang18 的主要技术变异来自与条件耦合的文库，而非供体；按错误的变量整合不会产生任何效果。第二，整合的目的是统一坐标系：Harmony、RPCA 与 CCA 都消除了条件纯聚类，且未合并细胞类型；压力测试表明，在存在非共享细胞类型时，CCA 是三者中最不保守的。整合结果只用于找邻居，差异表达必须回到原始计数。第三，细胞不是重复，样本才是重复：零假设实验中，逐细胞 Wilcoxon 检验在 35 种分组下全部报告了上百个假阳性基因，拟bulk edgeR 则几乎全部为零。即使 ICC 只有 0.017，每名供体数百个细胞也会带来约 6.8 倍的设计效应。第四，配对设计应写进模型：供体区组因子使 BCV 下降约三分之一，muscat 与 DESeq2 的结论高度一致。第五，丰度变化与状态变化要分开：嵌入空间的选择决定了 miloR 在检验什么，6 小时刺激下的”显著”组成变化需要结合时间尺度与注释稳定性解读。

整合后的统一图谱是后续所有高级分析的共同输入。专题 7.2 将在此基础上重建细胞分化的拟时序轨迹；本专题看到的”同一细胞类型内部的状态迁移”，正是拟时序与 RNA Velocity 试图刻画的连续变化。专题 7.3 推断细胞通讯与调控网络，本专题检出的干扰素响应基因将在那里与 STAT/IRF 家族调控子相互印证。第 9 章则以注释后的图谱作为空间解卷积的参考（参见第 9 章）。

  4. 全局线性校正假设所有细胞受到同样的批次偏移，并对每个基因减去批次均值。但单细胞批次效应往往是细胞类型特异的，且各批次的细胞组成不同，全局校正会把组成差异误当作批次偏移扣除，也无法处理不同细胞类型偏移方向不同的情形。Harmony 先做带多样性惩罚的软聚类，再在每个聚类内部、以隶属概率为权重分别估计批次偏移，从而允许批次效应随细胞类型变化。

  5. 若批次 1 的细胞 a 位于批次 2 细胞 b 的 k 近邻之内，同时 b 也位于 a 在批次 2 中的 k 近邻之内，则二者构成一对 MNN。批次独有的细胞类型在另一批次中没有相似的细胞，其最近邻即使存在，也不会反过来把它当作最近邻，因此无法形成”互相认可”的配对。CCA 在两个数据集相关性最大的共享投影空间中找 MNN；RPCA 把每个数据集分别投影到对方的 PCA 空间中找近邻，要求锚点在双方各自的主成分空间中都成立，条件更严，所以更保守、更不易把不同细胞类型对齐。
