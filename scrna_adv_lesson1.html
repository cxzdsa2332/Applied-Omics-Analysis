37 专题概述

第 6 章的标准流程默认输入来自单一样本。然而真实研究几乎总是多样本的：多个供体、多个批次、多种处理条件。一旦合并多样本数据，技术批次效应便与生物学信号混杂。直接做 PCA 与聚类，往往得到”按样本分开”而非”按细胞类型分开”的结果。本专题首先讲解跨样本整合（Integration）如何在保留真实生物学差异的前提下消除批次效应，比较 Seurat 锚点、Harmony 与 scVI 三类方法，并用定量指标评估整合质量。随后转向多样本研究的两个核心统计问题：差异表达（Differential Expression，某细胞类型内部哪些基因变了）与差异丰度（Differential Abundance，哪些细胞类型或状态的比例变了）。贯穿全篇的一条统计原则是：以”细胞”为重复单位会严重低估方差、放大假阳性，正确的重复单位是”生物学样本”。本专题的每一个结论都在同一份真实数据上实测验证，读者可以逐段复现。

学习目标：理解批次效应与生物学信号的混杂机制，能用主成分回归诊断批次效应的来源；理解 MNN 锚点、Harmony 与 scVI 的算法原理及适用场景；掌握 Harmony 与 Seurat RPCA/CCA 整合的实操，能用 LISI 与”缺失细胞类型”压力测试评估批次混合度与过度整合风险；明确整合结果的使用边界；能用组内相关系数与设计效应定量解释伪重复，并通过零假设实验识别逐细胞检验的假阳性；掌握 muscat 拟bulk差异表达的配对设计与结果核验；理解组成数据约束，能运行 propeller 与 miloR 差异丰度检验，并区分”丰度改变”与”状态迁移”。

38 本专题使用的数据

38.1 一个用遗传变异”混样”的实验

本专题全程使用 Kang 等人发表的 IFN-β 刺激 PBMC 数据（Kang et al., 2018）。这项研究本身是一个方法学故事。作者想同时测量多名供体的单细胞转录组，又不愿为每名供体单独占用一个 10x 通道。那样做既昂贵，又会使”供体”与”通道”完全混杂。他们的办法是把 8 名系统性红斑狼疮患者的 PBMC 直接混在一起上样，测序后再依据 reads 中天然携带的 SNP 基因型，用自研的 demuxlet 算法把每个细胞”认领”回其供体（混样与遗传去卷积的原理参见专题 6.1）。混合细胞群被分为两份：一份用 IFN-β 刺激 6 小时（STIM），另一份不处理（CTRL），两份细胞分别上样、分别建库。demuxlet 的另一项收益是能识别来自不同供体的双细胞，数据中的 multiplets 列即为其判定结果。

muscData 中的 Kang18_8vs8 以 SingleCellExperiment 对象形式提供这份数据，包含 35,635 个基因 × 29,065 个液滴。元数据中有四列与本专题相关：ind（供体编号）、stim（条件）、cell（原作者注释的 8 种细胞类型）与 multiplets（demuxlet 判定）。

运行环境说明： 本专题的 R 代码依赖 Seurat（v5）、harmony、muscat、muscData、miloR、speckle、edgeR、DESeq2、presto、scater 与 lisi，均已在 R 4.5.2 / Seurat 5.5.1 / harmony 2.0.5 / muscat 1.24.0 / miloR 2.6.0 / speckle 1.10.0 环境下实测运行，正文所引数值均来自这次运行。Kang18_8vs8() 首次调用时需通过 ExperimentHub 联网下载约 39 MB 的数据，此后从本地缓存读取。除 scVI 与 scCODA 两段 Python 示意代码外，各步骤在普通笔记本上均可在一分钟内完成。

library(muscData)
library(SingleCellExperiment)
library(Seurat)

sce <- Kang18_8vs8()
dim(sce)                     # 35635 genes x 29065 droplets
table(sce$multiplets)        # demuxlet calls: singlet / doublet / ambs

# Keep demuxlet singlets that carry a cell-type label
sce <- sce[, sce$multiplets == "singlet" & !is.na(sce$cell)]
table(sce$cell, sce$stim)

# Build a Seurat object with gene symbols and the design columns
counts_mat <- counts(sce)
rownames(counts_mat) <- make.unique(as.character(rowData(sce)$SYMBOL))
md <- data.frame(ind  = factor(sce$ind),
                 stim = sce$stim,
                 cell = sce$cell,
                 row.names = colnames(sce))
md$sample <- paste(md$stim, md$ind, sep = "_")
kang <- CreateSeuratObject(counts_mat, meta.data = md,
                           min.cells = 3, min.features = 200)
kang

demuxlet 把 29,065 个液滴中的 24,679 个判为单细胞，3,169 个判为跨供体双细胞，1,217 个无法确定（ambs）。单细胞中另有 9 个缺少细胞类型标签，剔除后余 24,673 个细胞。构建 Seurat 对象时按 min.cells = 3, min.features = 200 再做一轮过滤，得到 15,701 个基因 × 24,562 个细胞（CTRL 12,261 个，STIM 12,301 个）。16 个”供体 × 条件”样本各含 461–2,738 个细胞。各细胞类型的细胞数见 表 1。

38.2 设计结构决定了能回答什么问题

这一设计的结构可以概括为一句话：供体与文库解耦，条件与文库耦合。由于 8 名供体的细胞在同一个文库中被一起处理，供体间差异不可能来自文库批次。这为后文以供体为重复单位的统计检验提供了干净的基础。每名供体同时出现在两种条件中，构成一个 8 对的配对设计，与第 4 章 airway 数据的 4 对细胞系配对设计同构（参见第 4 章）。反过来，CTRL 与 STIM 的细胞从未在同一个文库中出现，条件与文库批次完全混杂。

教学数据的一个诚实限定： 由于条件与文库完全对应，本数据中任何”STIM 相对 CTRL”的差异，在严格意义上都是”IFN-β 效应 + 文库批次效应”之和，无法从数据内部拆开。IFN-β 刺激引起的转录变化幅度极大，后文实测的干扰素刺激基因上调可达 \(2^6\)–\(2^8\) 倍，远超常见的文库间技术差异。因此本数据的主要结论在实践中可信，但对于效应量小的基因，这一混杂无法排除。设计自己的实验时，应让每个文库或批次同时包含各种条件的样本。

muscData::Kang18_8vs8() 与 Seurat 教程中常用的 ifnb（SeuratData::InstallData("ifnb")）来自同一实验。ifnb 是经 Seurat 团队过滤与重新注释的子集，只保留了条件标签，没有供体标签，因而无法用于任何需要生物学重复的分析。为使整合、差异表达与差异丰度三部分使用同一批细胞、结果可以前后对照，本专题统一使用 Kang18_8vs8。读者若按 Seurat 官方教程用 ifnb 练习整合部分，代码只需替换对象与列名，具体数值会因细胞过滤不同而略有差别。

39 跨样本整合与批次校正

39.1 批次效应的本质

批次效应（Batch Effect）指由实验处理或测量过程引入、并随技术分组系统变化的表达差异。其来源包括采集后的保存时间、组织解离流程、建库日期、操作者、试剂批号、测序平台和 10x 化学版本等。同一种细胞类型在不同批次中可能具有不同的检出率、表达偏移或噪声结构，于是在 PCA/UMAP 中形成按批次分开的团块。但“样本分开”只是现象，不能单凭图形就认定它是技术误差。

39.1.1 先区分技术批次、供体差异与研究条件

供体差异本身属于生物学变异，不能直接定义为技术批次效应。不同供体的遗传背景、年龄、疾病状态和细胞组成都可能改变表达。若每名供体恰好单独建库，供体与建库效应就同时存在于“样本标签”中，难以仅凭标签区分。为了统一细胞类型注释，有时会在嵌入中调整部分供体差异；这是一种服务于分析目标的选择，并不表示这些差异原本都是技术噪声。

同一变量在不同任务中的角色可以不同。比如疾病状态在研究疾病效应时是目标信号；在构建跨疾病的细胞类型参考图谱时，又可能希望让共享细胞类型在同一个坐标系中对应。应先写清楚“要保留什么差异、要调整什么差异”，再决定模型中的批次变量。不能先挑出使 UMAP 最均匀的标签，再反过来把它定义为技术批次。

39.1.2 批次如何进入表达：整体尺度、基因偏移与状态依赖

以标准化后的对数表达为例，可将一个基因的观测概念性地写为

\[ Y_{gi}=\mu_g+f_g(z_i)+h_g(b_i,z_i)+\varepsilon_{gi}, \]

其中 \(z_i\) 表示生物学状态，\(f_g(z_i)\) 为希望研究或保留的表达结构，\(b_i\) 为批次，\(h_g\) 为技术因素的影响，\(\varepsilon_{gi}\) 为剩余随机变异。这是描述不同来源的概念分解，并不意味着只凭观测表达就能唯一估计每一项。最简单的模型令 \(h_g(b_i,z_i)=\gamma_{g,b_i}\)，即同一批次对同一基因施加固定偏移；更一般的情形允许该偏移随细胞状态变化。

如果一个文库只因测序更深而使所有基因计数按近似共同倍数增加，文库大小标准化可处理主要的尺度差异。如果某些基因在同一批次中特别容易被检出，则需要基因特异的批次系数。若解离或捕获过程对不同细胞状态的影响不同，同一个基因的批次偏移还可能依赖细胞类型。标准化、全局回归和局部整合处理的是不同层面的结构，不能互相替代。

批次还可能影响方差、零计数比例和细胞组成。例如某流程对一类脆弱细胞的回收率较低，即使把剩余细胞的表达分布对齐，也不能据此恢复未被捕获的细胞。因此“表达空间看起来混合”与“技术过程的全部影响已消除”是两种不同判断。

39.1.3 混杂决定了能否分离效应，而不只是校正难度

当批次标签与研究条件相关时，条件差异就可能混入批次差异。应区分三种设计：

平衡设计是有利条件，不是唯一可分析的设计；不平衡也不自动意味着不可分析。关键是设计矩阵是否满秩，以及分离目标效应所需的比较是否有实际样本支持。完全混杂时，即使增加同一批次中的细胞数、提高测序深度或换一种整合算法，也不能补回缺失的实验对照。应尽可能在建库前随机分配样本，让不同条件跨批次出现，并记录每一步技术信息。

一个著名的教训：物种还是测序批次？ 2014 年，小鼠 ENCODE 联盟的一项比较转录组研究报告：人与小鼠的多种组织样本首先按物种而非按组织聚类，提示同一物种不同组织之间的相似性高于不同物种的同一组织。Gilad 与 Mizrahi-Man 从原始 FASTQ 的读段标题中复原了测序仪与泳道信息，发现人与小鼠的样本基本分处不同的测序批次，物种与批次高度混杂。校正批次后，样本转而按组织聚类（Gilad & Mizrahi-Man, 2015）。这个例子说明，“按样本分开”的聚类结构本身不足以判断差异来自生物学还是技术，必须回到实验设计中查看二者是否混杂（图 1）。

39.2 回顾：bulk 转录组如何处理批次效应

在进入单细胞方法之前，先回顾 bulk RNA-seq 的做法（参见第 4 章）。bulk 数据处理批次效应有两条路径。第一条是建模：在差异表达的设计矩阵中加入批次变量，如 ~ batch + condition，同时估计条件效应与批次效应，并据此计算条件效应的不确定性。第二条是移除：从表达矩阵中扣除估计的批次成分，得到一份用于 PCA、热图等探索分析的校正矩阵。limma::removeBatchEffect() 采用线性模型扣除批次成分；ComBat 的常见形式还包含批次相关的尺度调整与经验贝叶斯收缩，不能简单等同于逐批次减均值。本节用前一种函数说明“模型内调整”与“先校正、再检验”的区别。

39.2.1 bulk 中的“全局”究竟指什么

bulk 表达矩阵每一列是一个生物学样本，通常混合了许多细胞。这里的“全局”并不是给所有基因减去同一个常数，而是每个基因各自估计批次效应，但同一基因的批次系数在所分析样本间共享。在后面的两批次模型中，基因 \(g_1\) 可以在 B2 中升高、\(g_2\) 可以降低；限制在于同一基因不能针对不同生物学状态自动采用不同的 B2 偏移。

bulk 的平均化可以减少单细胞抽样噪声，却不会自动消除组成变化。如果处理使免疫细胞比例升高，即便每种细胞内部的表达都不变，混合组织中免疫相关基因也会升高。在线性表达尺度上，混合信号可近似写成 \(m^{\mathrm{bulk}}_{gj}=\sum_t w_{tj}m_{gtj}\)，其中 \(m_{gtj}\) 是类型 \(t\) 的表达谱，\(w_{tj}\) 是其 RNA 贡献权重。该权重不必等于细胞数比例，因为不同类型每个细胞的 RNA 总量可能不同。对混合表达取对数之后，也不能直接把它等同于各类型对数表达的加权平均。

因此，bulk 中使用 ~ batch + condition 的含义是“在指定的共同效应模型下估计调整后的条件差异”，不是声称组织组成已经相同，或所有技术因素都已被识别。是否需要另外建模组成取决于研究问题；如果组成变化本身就是处理结果，加入组成协变量还会改变所估计效应的含义。

关于模拟数据： 本节的两组数据都是人为生成的，用于在”真相已知”的条件下说明批次校正的原理，不代表任何真实实验。本专题其余部分仍使用 Kang18 真实数据。下列示例可独立运行，需安装 R 包 edgeR、limma 与 RANN。

模拟设计为 2 个批次 × 2 种条件 × 每组 3 个重复，共 12 个样本、2,000 个基因。其中 200 个基因受处理影响（自然对数尺度上 ±0.8，约 2.2 倍）；每个基因另有一个服从 \(\mathcal{N}(0,\ 0.8^2)\) 的批次效应，作用于批次 B2 的全部样本。每个批次都同时包含两种条件，属于平衡设计。

39.2.2 计数如何生成：负二项模型与对数连接

设 \(K_{gj}\) 为基因 \(g\) 在样本 \(j\) 中的计数，\(C_j=\mathbb{1}(\text{treat})\)、\(B_j=\mathbb{1}(\text{B2})\) 为取值 0 或 1 的指示变量。本例的数据生成模型为

\[ K_{gj}\sim\operatorname{NB}(\mu_{gj},\phi),\qquad \log\mu_{gj}=\log m_g+\beta_g C_j+\gamma_g B_j, \qquad \operatorname{Var}(K_{gj})=\mu_{gj}+\phi\mu_{gj}^2. \]

这里 \(m_g\) 是 B1 中 ctrl 样本的基准期望计数，\(\beta_g\) 是处理效应，\(\gamma_g\) 是 B2 相对 B1 的批次效应。对数尺度上的相加对应计数尺度上的相乘：B2 中 treat 样本的期望计数为 \(m_g\exp(\beta_g)\exp(\gamma_g)\)。例如 \(m_g=100\)、\(\beta_g=0.8\)、\(\gamma_g=0.8\) 时，B1/ctrl、B1/treat、B2/ctrl、B2/treat 的期望计数依次约为 100、223、223、495。处理与批次在这里是两个可分离的乘性因素，没有交互作用。

下面的代码先建立样本表，再生成均值矩阵 mu（2,000 行基因 × 12 列样本），最后从负二项分布抽取计数。base_mu 对应 \(m_g\)；de_lfc 对应 \(\beta_g\)，前 200 个元素为 ±0.8，其余为 0；batch_lfc 对应 \(\gamma_g\)，每个基因一个值，B2 的所有样本共享该值。rnbinom(..., size = 10) 的离散度为 \(\phi=1/10=0.1\)，所以方差大于均值。is_de 保存模拟真相，仅用于事后评价，拟合模型并不知道哪些基因是真阳性。

library(edgeR)
library(limma)

set.seed(2026)
n_genes <- 2000; n_de <- 200
meta <- data.frame(
    batch     = factor(rep(c("B1", "B2"), each = 6)),
    condition = factor(rep(rep(c("ctrl", "treat"), each = 3), 2), levels = c("ctrl", "treat")),
    row.names = paste0("S", 1:12))

base_mu   <- exp(runif(n_genes, log(20), log(2000)))                 # baseline expression
de_lfc    <- c(sample(c(-1, 1), n_de, TRUE) * 0.8, rep(0, n_genes - n_de))
batch_lfc <- rnorm(n_genes, 0, 0.8)                                   # gene-specific batch shift
is_de     <- de_lfc != 0
mu <- sapply(1:12, function(j) base_mu * exp(de_lfc    * (meta$condition[j] == "treat") +
                                             batch_lfc * (meta$batch[j] == "B2")))
counts <- matrix(rnbinom(length(mu), mu = mu, size = 10), n_genes,
                 dimnames = list(paste0("g", 1:n_genes), rownames(meta)))

39.2.3 标准化与设计矩阵分别解决什么问题

DGEList(counts) 保存原始计数和文库信息；normLibSizes() 默认采用 TMM 标准化，估计样本间的相对尺度因子，并不把计数矩阵改写成“无批次计数”。在 edgeR 的拟合模型中，有效文库大小 \(L_j^{\mathrm{eff}}\) 作为偏置项（offset）进入模型：

\[ \log\mu_{gj}=\log L_j^{\mathrm{eff}}+\alpha_g+\gamma_g B_j+\beta_g C_j. \]

偏置项的系数固定为 1，用于处理测序深度与整体组成尺度；\(\gamma_g\) 则允许不同基因有不同的批次偏移。两者不能互相替代。前面的生成模型没有额外设置样本特异的测序深度，此处仍按实际 RNA-seq 分析流程估计标准化因子。cpm(y, log = TRUE) 生成带先验计数的 log2-CPM，供后续 PCA 和线性模型演示使用；生成数据时的 ±0.8 是自然对数效应，换为 log2 倍数变化约为 \(\pm0.8/\log 2=\pm1.15\)。

y    <- normLibSizes(DGEList(counts))
lcpm <- cpm(y, log = TRUE)

# PCA on the 500 most variable genes: % variance of PC1 and PC2
pca_var <- function(M) {
    pc <- prcomp(t(M[order(apply(M, 1, var), decreasing = TRUE)[1:500], ]))
    round(100 * pc$sdev[1:2]^2 / sum(pc$sdev^2), 1)
}
pca_var(lcpm)

pca_var() 先按行方差选出 500 个基因，再将矩阵转置为“样本 × 基因”，使 PCA 的每个点对应一个样本。prcomp() 默认对基因中心化而不做单位方差缩放；输出是 PC1、PC2 的方差贡献率。该函数每次都会重新选择高变基因，因此校正前后的贡献率同时受校正和基因集合变化影响；贡献率本身也不能说明主成分对应批次还是条件，需要结合样本分组查看。

39.2.4 加入批次后，条件系数比较的是什么

在加性模型下，同一批次内 treat 与 ctrl 的期望对数表达差均为 \(\beta_g\)：B1 中比较 \(\alpha_g+\beta_g\) 与 \(\alpha_g\)，B2 中比较 \(\alpha_g+\gamma_g+\beta_g\) 与 \(\alpha_g+\gamma_g\)，批次项都会相消。模型将这些有条件的比较合并起来，而不是直接比较所有 treat 与所有 ctrl 的未调整均值。真实计数模型中的合并还受文库大小、均值与离散度影响，不必等于两个批次差值的简单算术平均。

为什么不平衡时忽略批次会有偏差？在简化的对数表达线性模型 \(Y_g=a_g+b_gC+c_gB+\varepsilon_g\) 中，若只回归 \(C\)，其条件系数在误差与设计变量不相关的前提下满足

\[ b_g^{\mathrm{omit}}=b_g+c_g\frac{\operatorname{Cov}(C,B)}{\operatorname{Var}(C)}. \]

后半项就是遗漏变量带来的混入。若真实条件效应为 0，批次效应为 1 个 log2 单位，且 treat 中 80% 来自 B2、ctrl 中仅 20% 来自 B2，那么未调整的组间均值差为 \(1\times(0.8-0.2)=0.6\) 个 log2 单位，约为 1.52 倍。这个差异完全由不平衡分配产生。若两组的批次比例相同，该混入项为 0，但未解释的批次变异仍可损害功效；这正是本节平衡模拟主要展示的情形。该公式用于解释线性模型，不能未经推导直接套作所有负二项模型系数的精确等式。

共同条件效应也是一个假设。~ batch + condition 不含交互项，要求不同批次中的处理效应相同；~ batch * condition 则允许条件效应随批次改变，此时条件主系数只描述参考批次，还需结合交互系数解释其他批次。交互需要各组合中的重复支持，不能为完全缺失的组合创造信息。

可识别性： 该模型能够区分处理与批次，是因为两个批次中都有 ctrl 和 treat。如果所有 ctrl 都在 B1、所有 treat 都在 B2，\(B_j\) 与 \(C_j\) 完全相同，设计矩阵不满秩，只能估计 \(\beta_g+\gamma_g\)，无法分别估计二者。加入更多校正步骤不能恢复实验设计中不存在的信息。

39.2.5 三种检验策略对应哪些模型

下面的 ql_fdr() 保留原始计数作为响应：estimateDisp(y, des) 在指定设计下估计负二项离散度；glmQLFit() 拟合均值模型并估计、收缩准似然变异；glmQLFTest() 检验条件系数；topTags() 返回经 Benjamini–Hochberg（BH）方法调整的 FDR 值。离散度必须结合设计估计，因此两种设计分别调用 estimateDisp()。按 rownames(counts) 重排结果，是为了让显著性向量与 is_de 一一对应，避免 topTags() 的排序打乱真阳性评价。

前两条路径分别拟合 \(\log\mu_{gj}=\log L_j^{\mathrm{eff}}+\alpha_g+\beta_g C_j\) 和包含 \(\gamma_g B_j\) 的完整模型。平衡设计下，忽略批次未必使条件效应的点估计产生系统偏差，但批次差异会进入未解释变异，增大离散度估计并降低检验功效。若设计不平衡，忽略批次还可能使条件系数吸收部分批次效应。

# Count true and false positives at FDR < 0.05
score <- function(fdr) c(TP = sum(fdr < 0.05 & is_de), FP = sum(fdr < 0.05 & !is_de))
ql_fdr <- function(des, coef) {
    fit <- glmQLFit(estimateDisp(y, des), des)
    topTags(glmQLFTest(fit, coef = coef), n = Inf)$table[rownames(counts), "FDR"]
}

# (1) Ignore the batch
score(ql_fdr(model.matrix(~ condition, meta), 2))
# (2) Model the batch in the design matrix
score(ql_fdr(model.matrix(~ batch + condition, meta), 3))
# (3) Remove the batch first, then test the corrected matrix as if it were raw data
corrected <- removeBatchEffect(lcpm, batch = meta$batch,
                               design = model.matrix(~ condition, meta))
fit_rbe <- eBayes(lmFit(corrected, model.matrix(~ condition, meta)))
score(p.adjust(fit_rbe$p.value[, 2], "BH"))
pca_var(corrected)

第三条路径改变了响应矩阵。令 \(Y_{gj}\) 为 lcpm 中的 log2-CPM，removeBatchEffect() 联合拟合条件与批次的线性模型，然后仅扣除估计的批次部分。用中心化的批次变量 \(\widetilde B_j\) 表示其批次编码，可写成

\[ Y_{gj}=a_g+b_g C_j+c_g\widetilde B_j+\varepsilon_{gj},\qquad Y^{\mathrm{corr}}_{gj}=Y_{gj}-\widehat c_g\widetilde B_j. \]

batch = meta$batch 指定要移除的因素，design = model.matrix(~ condition, meta) 指定需要保留的条件结构；design 并不是要被减掉的部分。函数默认批次对比编码的尺度可能不同于 0/1 编码，但不改变拟合的批次差异。返回值仍是连续的 log2 表达矩阵，不是原始计数。limma 函数文档明确将该输出用于 PCA、热图等探索分析，并建议在差异检验时直接把批次纳入模型。

在完整模型中，校正后矩阵保留的是 \(a_g+\widehat b_gC_j+\widehat\varepsilon_{gj}\)。它不是只剩条件的拟合均值，随机残差仍在；因此“移除批次”也不表示两个批次的每个样本都应完全重合。design 的保护只针对模型中可识别、正确指定的结构：如果条件与批次完全相同，同时声明“保留条件、去掉批次”并不能让数据把两者区分开。

ComBat 的常见连续表达模型还允许批次相关的残差尺度不同，概念上可写作 \(Y_{gj}=a_g+X_j^{\mathsf T}b_g+\gamma_{g,b(j)}+\delta_{g,b(j)}\varepsilon_{gj}\)，并跨基因借用信息以稳定位置与尺度估计，相关选项见 ComBat 函数文档。它增加了估计策略，却没有改变可识别性原则。其常见连续表达版本与本节的 removeBatchEffect() 都不应直接用于未经变换的 RNA-seq 原始计数以替代计数模型；针对计数设计的其他方法需要按各自的分布假设和下游推断流程另行讨论。

随后 lmFit(corrected, model.matrix(~ condition, meta)) 却把校正矩阵当作新的观测，拟合普通线性模型；eBayes() 对基因残差方差做经验贝叶斯收缩，得到调节后的 t 检验。它不会自动获知上一步估计批次效应已消耗的自由度。因此第三条路径在本例中属于特意设置的错误用法。

还需注意，前两条路径用 edgeR 的计数模型，第三条用未经 voom 加权的 log2-CPM 线性模型，三者的检出数并非只由批次处理方式决定。为了更直接检查“先移除、再检验”的影响，下面固定为同一种 log2-CPM / limma 框架，仅改变批次的处理位置，比较原本没有处理效应的 1,800 个基因的原始 P 值。

# Calibration on the 1,800 null genes: share of raw p < 0.05 (nominal 5%)
fit_design <- eBayes(lmFit(lcpm, model.matrix(~ batch + condition, meta)))
c(remove_then_test = mean(fit_rbe$p.value[!is_de, 2] < 0.05),
  batch_in_design  = mean(fit_design$p.value[!is_de, 3] < 0.05))

39.2.6 如何解释检出数与 P 值校准

本例未校正矩阵的前 500 个高变基因 PCA 中，PC1 解释 75.8% 的变异，PC2 解释 8.5%。原代码只打印方差贡献率；判断批次或条件是否分开，还需查看 PCA 得分与分组的关系。校正矩阵能够减小批次对可视化的影响，但图上分组改善不等于后续检验有效。三种检验策略的结果见 表 5。

score() 用已知真相统计真阳性（TP）和假阳性（FP），阈值均为 BH 调整值小于 0.05。FDR 控制的是重复实验意义下错误发现比例的期望，并不要求每一次实验都恰好只有 5% 的显著基因是假阳性，也不等同于非差异基因中原始 P 值小于 0.05 的比例。后者在这里用作零假设下的校准诊断。

结果有两层含义。第一，忽略批次的代价是功效大幅下降：200 个真实差异基因只检出 26 个。第二，“先移除、再检验”检出的真阳性更多，但假阳性也更多。相同 limma 框架下，先移除批次的零假设基因有 7.7% 的 P 值小于 0.05，批次写入设计矩阵时为 5.8%，后者更接近名义水平。一次模拟不能证明一种方法总是优于另一种，但可展示错误传播不确定性的后果。

自由度问题可以在本例的平衡线性模型中直接推导。完整设计有 12 个样本、3 个独立系数，残差自由度为 \(12-3=9\)。先估计并扣除批次，再只拟合截距和条件，第二次拟合仍把自由度记为 \(12-2=10\)。由于平衡设计中中心化后的批次列与条件列正交，两种拟合的残差平方和（RSS）相同；但在经验贝叶斯收缩之前，错误流程用 \(\mathrm{RSS}/10\) 代替 \(\mathrm{RSS}/9\)，把残差方差低估为正确值的 0.9 倍。经验贝叶斯收缩不能自动补回遗漏的批次自由度。

设计不平衡时，还存在批次与条件相关、校正后观测的协方差未被后续模型正确处理等问题，不能仅靠手动改一个自由度修复。偏差大小取决于批次数、设计结构和拟合方法，不能断言它总随不平衡程度单调增加。因此本节的实践原则是：差异检验在原始计数的模型中处理批次；为探索分析生成的校正矩阵用于 PCA、热图等可视化。真实 RNA-seq 数据若采用 limma 路线，应使用 voom 等方法处理均值与方差的关系，并在同一个拟合模型中纳入批次。

39.3 从 bulk 到单细胞：全局校正为何失效

前面的全局加性模型为每个基因估计一个批次偏移，并假设该偏移不随样本的生物学状态改变。如果只按批次校正、不在模型中保护生物学变量，批次间的组成差异也可能被误认为批次效应。bulk 数据并不天然免疫这类问题：混合组织的细胞比例改变、批次与条件混杂，同样会使全局校正失效。单细胞数据把不同细胞类型直接作为表达矩阵的不同列，使组成不平衡与细胞类型特异的批次响应尤为突出。

39.3.1 分析单位改变后，为什么需要局部对应

bulk 的一列是混合样本，单细胞的一列是某个具体状态的细胞。把全部细胞按批次求均值时，不再是在比较两个可直接对应的个体：B1 的均值可能主要由 T 细胞决定，B2 的均值却主要由单核细胞决定。二者的差既包含“同一种细胞测得不同”，也包含“测到了不同种类的细胞”。即使总细胞数相同，组成仍可完全不同。

与此同时，基因在不同类型中的表达水平、捕获情况和技术响应可能不同。若某基因在 A 型中的 B2 偏移为 +1，在 B 型中为 −1，那么两型平衡时全局均值差可以恰好为 0，然而每型内部仍各有一个单位的批次分离。此时“全局批次均值已经一致”恰恰掩盖了局部失配。因此需要在相似细胞或相似状态之间比较，而不只是让整份矩阵的批次均值相同。Bioconductor 单细胞整合教材也将未知或不同的细胞组成作为从全局线性校正转向单细胞专用方法的重要动机。

这里的“局部”不是先要求所有细胞都有确定的类型标签，而是寻找有共享表达结构支持的对应区域。它也不保证任何差异都应被校正：如果 B2 独有一个真实活化状态，算法需要保留其特异性，而不是把它强行贴到 B1 中最近但不等价的群体上。

39.3.2 数据生成模型：细胞类型主效应与类型特异的批次效应

下面的模拟把这两种情形放在一起。两种细胞类型 A、B 各有 30 个标志基因，标志基因在本类型中高出 2 个对数单位。批次 B1 中 80% 为 A 型，批次 B2 中只有 20% 为 A 型。批次效应只作用于标志基因以外的 240 个基因，且 A、B 两型的偏移各自独立随机生成（二者相关系数为 −0.07），即批次效应是细胞类型特异的。标志基因本身没有批次效应。

此处直接模拟连续的对数表达，不再生成负二项计数。设 \(X_{gi}\) 为基因 \(g\) 在细胞 \(i\) 中的对数表达，\(T_i\in\{A,B\}\) 为细胞类型，\(B_i=\mathbb{1}(\text{B2})\)，则

\[ X_{gi}=a_g+\delta_{gA}\mathbb{1}(T_i=A) +\delta_{gB}\mathbb{1}(T_i=B) +B_i\bigl[s_{gA}\mathbb{1}(T_i=A)+s_{gB}\mathbb{1}(T_i=B)\bigr] +\varepsilon_{gi}. \]

其中 \(a_g\sim\mathcal N(1,0.3^2)\) 是基因基准表达；A 型标志基因取 \(\delta_{gA}=2,\delta_{gB}=0\)，B 型标志基因反之，其余基因两者均为 0。\(s_{gA}\)、\(s_{gB}\) 是 B2 相对 B1 的类型特异批次偏移，对应代码中的 shiftA、shiftB；标志基因的两个偏移都固定为 0，其余基因各自独立抽取自 \(\mathcal N(0,0.6^2)\)。噪声 \(\varepsilon_{gi}\sim\mathcal N(0,0.5^2)\)。这里的 \(\delta\) 用于描述生成真相；若做回归，由于两种类型指示变量之和为 1，应选一个参考类型，避免与截距重复。

代码中的 mu 此时是对数尺度的无噪声均值矩阵，与上一节计数尺度的 mu 含义不同。matrix(rnorm(n_genes, 1, 0.3), n_genes, length(type)) 会把长度为 300 的基准向量重复填入每一列，所以同一基因在所有细胞中共享 \(a_g\)。随后按细胞类型添加标志信号，只对 B2 细胞添加相应的类型特异批次偏移，最后加入逐基因、逐细胞的独立噪声。sample() 使细胞组成围绕 80%/20% 随机波动，并非精确固定为这两个比例。

library(limma)

set.seed(2026)
n_genes <- 300
markA <- 1:30; markB <- 31:60
type  <- c(sample(c("A", "B"), 1000, TRUE, c(0.8, 0.2)),    # batch B1: mostly type A
           sample(c("A", "B"), 1000, TRUE, c(0.2, 0.8)))    # batch B2: mostly type B
batch <- rep(c("B1", "B2"), each = 1000)

mu <- matrix(rnorm(n_genes, 1, 0.3), n_genes, length(type))
mu[markA, type == "A"] <- mu[markA, type == "A"] + 2
mu[markB, type == "B"] <- mu[markB, type == "B"] + 2
# Cell-type-specific batch effect on non-marker genes only
shiftA <- c(rep(0, 60), rnorm(n_genes - 60, 0, 0.6))
shiftB <- c(rep(0, 60), rnorm(n_genes - 60, 0, 0.6))
mu[, type == "A" & batch == "B2"] <- mu[, type == "A" & batch == "B2"] + shiftA
mu[, type == "B" & batch == "B2"] <- mu[, type == "B" & batch == "B2"] + shiftB
X <- mu + matrix(rnorm(length(mu), 0, 0.5), n_genes)       # log-scale expression
round(cor(shiftA[-(1:60)], shiftB[-(1:60)]), 2)            # type A vs type B batch shifts

39.3.3 为什么批次均值差会混入细胞组成

令 \(p_b=P(T=A\mid\text{batch}=b)\)。对一个 A 型标志基因，真实批次效应为 0，但两批次的总体均值仍有

\[ E(X_g\mid\text{B2})-E(X_g\mid\text{B1}) =2(p_2-p_1)=2(0.2-0.8)=-1.2. \]

B 型标志基因的对应差为 \(+1.2\)。因此，跨批次的总体表达差并不等于同一种细胞内的技术偏移。下列 d 是“先混合细胞类型、再算批次均值”的差；模拟中得到约 −1.23 和 +1.23，而非恰好 ±1.2，是因为实现的细胞比例与噪声具有随机波动。

这个例子可推广为一个期望均值的精确分解。以 B1 为参考，令类型 \(t\) 的参考均值为 \(\mu_{gt}\)，B2 中同类型的技术偏移为 \(\Delta_{gt}\)，两个批次的类型比例分别为 \(p_{1t}\)、\(p_{2t}\)。暂不引入同类型内的真实条件变化，则对这里的单细胞对数表达有

\[ E(X_g\mid b=2)-E(X_g\mid b=1) =\underbrace{\sum_t(p_{2t}-p_{1t})\mu_{gt}}_{\text{组成差异}} +\underbrace{\sum_t p_{2t}\Delta_{gt}}_{\text{类型加权的技术差异}}. \]

标志基因的 \(\Delta_{gt}=0\)，所以其期望总体批次差全部来自第一项；非标志基因也可能同时包含第二项，实际样本均值还叠加有限抽样噪声。若还存在真实条件响应，均值差中会再混入相应的类型加权生物学变化。单凭一个总体差值，不能把这些来源唯一分开。这里是在对数表达已定义后的细胞间求均值，不能与前面 bulk 在线性尺度上的混合公式互换。

# Global batch-mean difference on marker genes, whose true batch effect is 0
d <- rowMeans(X[, batch == "B2"]) - rowMeans(X[, batch == "B1"])
round(c(markers_A = mean(d[markA]), markers_B = mean(d[markB])), 2)

39.3.4 四种校正分别拟合什么模型

下面比较的四种处理，区别在于模型是否包含类型主效应，以及是否允许批次效应随类型改变。表中的系数均按基因分别估计，\(B_i\) 仍为 B2 的指示变量。

design = model.matrix(~ type) 只增加类型主效应，相当于为 A、B 两型设置不同的基准表达；它并没有增加“类型 × 批次”交互项。因此在同一基因上，模型仍要求 A、B 两型具有相同的 B2−B1 偏移。最后一种按类型分别拟合的操作则允许两种偏移不同；就本例的均值结构而言，相当于包含 type * batch 的完整交互模型，并移除其中与批次有关的主效应及交互成分。实际分开拟合还允许各类型独立估计残差方差。

两种能力必须分别判断。保护类型主效应，解决的是“不要用类型基准差解释组成变化”；允许类型与批次交互，解决的是“同一个技术流程对不同类型可产生不同偏移”。前者不能自动获得后者。若某型在一个批次中完全缺失，该类型的跨批次差便没有观测对照，交互模型也无法可靠估计这一缺失组合；增加公式复杂度不能替代共享状态。

39.3.5 report() 如何把模型失配变成可读指标

report() 的输入 M 始终是“300 个基因 × 2,000 个细胞”的对数表达矩阵，依次计算三类量：

  1. 同类型内批次质心差：先固定类型 \(t\)，求 B2 与 B1 的逐基因均值差，再计算欧氏范数 \(\mathrm{gap}_t=\sqrt{\sum_g(\overline M_{g,t,\mathrm{B2}}-\overline M_{g,t,\mathrm{B1}})^2}\)。它比较的是相同类型内部的批次差，而不是前面混合类型后的 d。总体无批次效应时目标为 0，有限样本下仍可因噪声大于 0。
  2. 标志基因对比：对 30 个 A 型标志基因，计算其在全部 A 型细胞与全部 B 型细胞中的均值差，再取基因平均。生成真值为 2；若校正后显著缩小，说明生物学信号被削弱。该指标只检查预设标志信号，不能代表全部生物学结构。
  3. 同批次近邻比例：prcomp(t(M), rank. = 10) 对细胞做 PCA，取前 10 个得分维度；RANN::nn2(..., k = 21) 返回包含自身的 21 个近邻，删除第一列后留下 20 个。将邻居的批次标签与中心细胞比较，输出平均同批次比例的百分数。该指标描述低维邻域混合，不能单独识别过度校正。
# Residual batch gap within each type, marker contrast, and kNN batch purity
report <- function(M) {
    gap <- sapply(c("A", "B"), function(t) {
        d <- rowMeans(M[, type == t & batch == "B2"]) - rowMeans(M[, type == t & batch == "B1"])
        sqrt(sum(d^2))
    })
    marker <- mean(rowMeans(M[markA, type == "A"]) - rowMeans(M[markA, type == "B"]))
    pcs <- prcomp(t(M), rank. = 10)$x
    nn  <- RANN::nn2(pcs, k = 21)$nn.idx[, -1]
    same_batch <- mean(matrix(batch[nn], ncol = 20) == batch)
    round(c(gap_A = gap[[1]], gap_B = gap[[2]], marker_A_vs_B = marker,
            same_batch_nbrs = 100 * same_batch), 2)
}

report(X)                                                              # uncorrected
report(removeBatchEffect(X, batch = batch))                            # global, batch only
report(removeBatchEffect(X, batch = batch, design = model.matrix(~ type)))  # global + type
X_local <- X
for (t in c("A", "B"))                                                 # per cell type
    X_local[, type == t] <- removeBatchEffect(X[, type == t], batch = batch[type == t])
report(X_local)

四种处理的结果见 表 7。“批次残差”为同一细胞类型内两个批次质心之间的欧氏距离，理想值为 0；“标志基因对比”为 A 型标志基因在 A、B 两型间的平均差，真实值为 2.00；“同批次近邻”为每个细胞的 20 个近邻中来自同一批次的比例。若批次完全混合，该比例的期望约为 69%，而不是 50%，因为每种细胞类型在两个批次中的数量本来就是 4:1。

这个混合基线需要以细胞类型为条件计算。如果类型保持分离，而且每种类型内部细胞来自 B1 的概率为 \(q_t\)，理想混合下随机选取中心细胞及其同类型邻居，两者来自同一批次的概率约为 \(q_t^2+(1-q_t)^2\)。名义比例 \(q_A=0.8\)、\(q_B=0.2\) 均给出 \(0.8^2+0.2^2=0.68\)；按本次抽样后的实际比例计算约为 69%。因此，强行把该指标降到 50% 并不是合理目标。此近似还忽略了有限样本中排除自身的微小修正。

39.3.6 用模型解释两种失败与局部校正的边界

这张表依次暴露了全局校正的两种失败。第一，组成差异被当作批次效应扣除。只按批次做全局校正时，B1 中 A 型细胞多，B2 中 B 型细胞多，A 型标志基因的批次均值之差因此为 −1.23，B 型标志基因为 +1.23。可这些基因的真实批次效应为 0，差异完全来自组成。校正把这部分生物学信号当作技术偏移扣除，A、B 两型的标志基因对比从 2.00 缩小到 1.24，约四成标志信号丢失；A 型细胞的批次残差反而从 9.30 增大到 14.55。

对标志信号的损失还可作一个近似计算。以 A 型标志基因为例，全局校正估计 B2−B1 的偏移约为 −1.2，因而将 B2 相对 B1 提高约 1.2。A 型细胞中只有约 20% 来自 B2，B 型细胞中却有约 80% 来自 B2，所以两类型总体均值之差变为 \(2+1.2(0.2-0.8)=1.28\)，接近实测 1.24。这说明即便对同一批次所有细胞施加相同校正，不同的类型组成仍会使跨类型的总体对比失真。

第二，细胞类型特异的批次效应无法用一个全局偏移消除。把细胞类型写入设计矩阵后，组成问题得到纠正，标志基因对比恢复为 2.00。但模型仍只能得到一个折中的批次系数 \(\widehat c_g\)；A、B 两型分别留下约 \(s_{gA}-\widehat c_g\)、\(s_{gB}-\widehat c_g\) 的批次差。除非 \(s_{gA}=s_{gB}\)，同一个系数无法同时将两者消为 0。因此批次残差仍为 6.86 与 6.74，每个细胞的 20 个近邻仍全部来自同一批次。

在本例比较的四种操作中，按细胞类型分别校正同时保留了标志信号并改善了批次混合：批次残差归零，近邻构成降至 68.5%。不过，质心距离归零是该方法在拟合数据上的直接结果：分类型估计并扣除均值差，本来就会使两批次的样本质心重合。它不能证明全部分布、连续状态或真实处理效应均得到正确保留；还需结合标志信号和邻域结构判断。此模拟也没有样本层面的生物学重复，因此不能把这些细胞用于推断性的差异表达检验。

按类型校正还依赖可靠标签。若已有独立参考注释，而且每种类型在各批次中都有足够细胞，可以按类型建模；它并非绝对不能用于真实数据。但在探索性研究中，标签可能尚未确定，或标签本身受到批次分离影响，此时就出现“需要先注释才能校正、又需要校正帮助注释”的依赖。粗类型标签也可能无法覆盖类型内部的连续状态；若某类型只存在于一个批次，该类型的生物学差异与批次效应更无法单靠分类型回归区分。

下文的整合方法尝试从数据中学习对应关系，减少对预先提供细胞类型标签的依赖：MNN 用跨批次互最近邻配对，Harmony 用软聚类中的局部回归，scVI 用包含批次协变量的非线性生成模型。前两者通过局部对应关系估计校正，scVI 则允许批次对表达的影响依赖细胞的潜在状态。它们比“每个基因一个固定偏移”更灵活，但都仍依赖共享生物学结构与可识别性假设，需要检验是否发生过度整合。

39.3.7 从模拟结果回到真实研究：三类证据应同时保留

第一类是设计证据：批次与条件是否可分离，各类型是否跨批次共享，独立样本是否足够。第二类是校正证据：相同类型内部的批次差是否减小，邻域中的批次混合是否符合组成给定的合理基线。第三类是保留证据：类型标志、条件响应、稀有群体及连续状态是否仍有支持。只优化第二类指标，可能把真实生物学结构一并消除。

本模拟的类型标签与标志基因真相已知，所以可以直接比较 2.00 是否保持、各型质心是否对齐。真实数据通常没有如此完整的答案，需要使用独立标志、参考注释、留出样本或缺失类型压力测试交叉核验。整合后的低维坐标主要服务于共同聚类、注释和状态对应；条件差异与组成变化仍需按样本重复结构，在合适的原始数据和模型中另行推断。尤其在本专题的 Kang18 设计中，对齐 CTRL 与 STIM 并不会使已经混杂的文库效应在统计上变得可分离。

39.4 先诊断，再整合

整合之前，应先回答两个问题：数据中是否存在需要校正的批次效应？如果存在，它来自哪个变量？主成分回归（PC regression）是最简单的诊断工具。它对每个主成分分别以候选变量（条件、供体、细胞类型）为自变量做线性回归，用决定系数 \(R^2\) 衡量该变量解释了这个主成分多少变异（Büttner et al., 2019）。

library(Seurat)

kang <- NormalizeData(kang)
kang <- FindVariableFeatures(kang, nfeatures = 2000)
kang <- ScaleData(kang)
kang <- RunPCA(kang, npcs = 30)

# PC regression: R^2 of each PC explained by condition / donor / cell type
pcs <- Embeddings(kang, "pca")
pc_r2 <- sapply(c("stim", "ind", "cell"), function(v)
    sapply(1:30, function(i) summary(lm(pcs[, i] ~ kang@meta.data[[v]]))$r.squared))
round(pc_r2[1:10, ], 3)

# Variance-weighted R^2 across all 30 PCs

结果呈现出清晰的分工（表 8）。PC1 几乎完全由细胞类型解释（\(R^2\) = 0.893），这是理想的生物学结构。PC2 却有 53.3% 的变异由条件解释，PC8 也有 25.7%。在全部 30 个主成分上按方差加权，细胞类型解释 49.6%，条件解释 8.1%，供体只解释 2.4%。这些数值说明，当前 PCA 中与条件标签关联的结构强于与供体标签关联的结构；但单变量回归不能判断关联来自 IFN-β 响应还是文库，也不能将这些 \(R^2\) 当作相互独立、可以直接相加的因果贡献。结合本专题“让共享细胞类型获得统一注释”的目标，后续以条件标签定义整合分组，而不是把供体设为主要整合变量；这一选择不表示条件差异已被证明是技术批次。较弱的供体关联与混样设计相容，也不意味着供体生物学差异不存在。

在本数据中，“批次”就是被研究的条件： 这里整合 stim 的目的，不是抹去 IFN-β 效应，而是让 CTRL 与 STIM 中的同一种细胞落到同一个坐标系里，以便统一聚类、统一注释，并在同一细胞类型内部比较两种条件。整合只作用于用于聚类的低维嵌入；差异表达仍然回到原始计数上做（见下文”整合结果的使用边界”）。这一用法要求读者始终清楚：校正后的嵌入中”看不到”条件差异，是设计使然，而不是条件差异不存在。

39.5 整合方法谱系

跨样本整合方法可大致分为三代，复杂度与计算代价递增：

  • 锚点法（Anchor-based，Seurat CCA/RPCA）：在样本对之间寻找互最近邻（Mutual Nearest Neighbors, MNN）作为锚点，再据此计算校正向量，将一个数据集对齐到另一个。RPCA 比 CCA 更快、更保守（不易过度整合），是大数据集的推荐选择。
  • Harmony：在 PCA 嵌入空间中迭代执行”软聚类 + 批次特异性线性校正”两步，直至批次在每个聚类内均匀混合（Korsunsky et al., 2019）。Harmony 不修改表达矩阵，只输出校正后的降维坐标，计算极快，适合数十万细胞规模的数据。
  • scVI（single-cell Variational Inference）：基于变分自编码器的深度生成模型，以负二项分布建模原始计数，将批次作为协变量编码进神经网络，输出批次校正后的隐变量空间与归一化表达（Lopez et al., 2018）。scVI 对复杂非线性批次效应的建模能力最强，但需要 Python 环境，大数据集通常还需要 GPU。

三类方法的权衡见 表 9。一项图谱级整合基准研究比较了十余种方法，发现在批次结构复杂的任务中，scANVI、Scanorama 与 scVI 等方法整体表现最好；Harmony 在批次结构较简单的任务上表现良好（Luecken et al., 2022）。没有一种方法在所有数据上都最优，因此整合后的定量评估不可省略。

39.6 三类方法的原理

39.6.1 互最近邻与锚点：Seurat CCA 与 RPCA

锚点法的思想源自 MNN 批次校正（Haghverdi et al., 2018）。设批次 1 中的细胞 \(a\) 与批次 2 中的细胞 \(b\)：若 \(b\) 位于 \(a\) 在批次 2 中的 \(k\) 个最近邻之内（\(k\) 近邻的含义见 图 2），同时 \(a\) 也位于 \(b\) 在批次 1 中的 \(k\) 个最近邻之内，则称二者构成一对 MNN。这一定义有一个关键性质：只有两个批次共有的细胞类型才可能形成 MNN。某批次独有的细胞类型，在另一批次中找不到”互相认可”的邻居。因此 MNN 对天然地给出了”哪些细胞是同一种状态”的配对证据，二者的表达差异向量就是该处批次效应的局部估计。

Seurat 在此基础上增加了三步（Stuart et al., 2019）。第一，先把两个数据集投影到一个共享空间再找 MNN。CCA 用典型相关分析寻找两数据集之间相关性最大的投影方向；RPCA 则把每个数据集投影到对方的 PCA 空间中，分别寻找近邻。第二，对每个锚点按其两端细胞近邻集合的重叠程度打分，思路与 SNN 权重相同（参见专题 6.3）。第三，对每个待校正细胞，用离它最近的若干锚点的校正向量加权平均，得到该细胞自己的校正量。CCA 擅长捕捉两数据集之间的共享相关结构，即便整体表达差异很大也能找到锚点，但也因此更容易把并不相同的细胞类型对齐。RPCA 要求锚点在双方各自的主成分空间中都成立，条件更严，因而更快、更保守。

下面用一个可以手算的小例子，把”找近邻 → 互相认可 → 求校正量”三步逐一走一遍，再回到真实数据检验锚点的质量。

39.6.1.1 第一步：在共享空间中寻找跨批次近邻

设批次 1（CTRL）有 5 个细胞：\(a_1\)–\(a_3\) 为单核细胞，\(a_4\)、\(a_5\) 为 T 细胞。批次 2（STIM）有 6 个细胞：\(b_1\)–\(b_3\) 为单核细胞，\(b_4\)、\(b_5\) 为 T 细胞，\(b_6\) 是一种只在 STIM 中出现的新状态。批次 2 的单核细胞与 T 细胞相对批次 1 整体平移了约 \((0.6,\ 0.3)\)，并叠加了少量随机扰动，这就是待估计的批次效应。为便于手算，这里用二维坐标代替真实分析中 CCA 或 RPCA 给出的 30 维共享空间；降维的作用与第 6 章相同，每个细胞仍是一个点，只是坐标数变少了（参见专题 6.3）。各细胞的坐标见 表 10。

与 SNN 不同，MNN 只在另一个批次中找近邻。取 \(k = 2\)，每个细胞都在对方批次中列出距离自己最近的 2 个细胞，得到两份”跨批次近邻名单”（表 11）。

39.6.1.2 第二步：只保留”互相认可”的配对

单向近邻关系并不可靠。\(b_6\) 在批次 1 中最近的细胞是 \(a_5\) 与 \(a_4\)，但这只是因为批次 1 中根本没有与它相同的细胞，“最近”的也未必”相似”。MNN 的要求是双向的：只有当 \(a\) 出现在 \(b\) 的名单上，同时 \(b\) 也出现在 \(a\) 的名单上时，二者才构成一对 MNN。对照 表 11 逐行检查，共得到 8 对 MNN（表 12）。

这张表说明了三件事。第一，8 对 MNN 全部连接同一种细胞，没有一对跨越细胞类型。第二，\(b_6\) 没有任何 MNN：它名单上的 \(a_4\)、\(a_5\) 都把 \(b_4\)、\(b_5\) 排在它前面，不”认可”它。这正是”批次独有的细胞类型找不到 MNN”的具体体现。第三，\(a_1\) 虽然是正常的单核细胞，也没有 MNN：它看中的 \(b_1\)、\(b_2\) 更偏爱 \(a_2\)、\(a_3\)。在真实数据中，大多数细胞都不直接参与任何锚点，它们的校正量要从附近的锚点”借用”。

39.6.1.3 第三步：从配对向量到每个细胞的校正量

每对 MNN 的配对向量都是批次效应的一个局部估计，但单个估计的噪声很大。真实平移为 \((0.6,\ 0.3)\)，而 \(a_5\)–\(b_4\) 给出 \((0.0,\ 0.8)\)，\(a_4\)–\(b_5\) 给出 \((1.2,\ -0.1)\)。对多个配对取平均可以抵消噪声：4 对单核细胞的平均向量为 \((0.45,\ 0.20)\)，4 对 T 细胞的平均向量为 \((0.60,\ 0.35)\)，都已接近真实值。

真实方法不是对全体锚点取一个总平均，而是为每个待校正细胞 \(c\) 单独计算校正量：

\[ \Delta_c = \frac{\sum_{j} w_{cj}\, v_j}{\sum_{j} w_{cj}} \]

其中 \(v_j\) 为第 \(j\) 个锚点的配对向量，\(w_{cj}\) 为该锚点对细胞 \(c\) 的权重。距离 \(c\) 越近、锚点得分越高，权重越大；只有离 \(c\) 最近的若干个锚点参与计算。校正后的坐标为 \(c - \Delta_c\)。由于权重随距离衰减，单核细胞主要借用单核细胞锚点的向量，T 细胞主要借用 T 细胞锚点的向量。这就是锚点法能够处理”细胞类型特异的批次效应”的原因。

\(b_6\) 自己没有锚点，离它最近的是 T 细胞锚点，因此它大致按 T 细胞的平均向量平移：\((7.5,\ 3.0) - (0.60,\ 0.35) = (6.90,\ 2.65)\)。平移后它与最近的 \(a_5\) 仍相距约 2.3，作为一种独立状态保留了下来，没有被并入 T 细胞。

39.6.1.4 \(k\) 的选择：\(k = 3\) 时发生了什么

把 \(k\) 从 2 提高到 3，每份名单都多了一个候选，MNN 对从 8 对增加到 15 对（表 13）。

结果呈现出一个典型的权衡。对单核细胞而言，更大的 \(k\) 带来更多正确配对，平均向量恰好等于真实平移 \((0.6,\ 0.3)\)。对 T 细胞而言，批次 2 只有 2 个 T 细胞，\(k = 3\) 迫使 \(a_4\)、\(a_5\) 把第三个名额给了 \(b_6\)。\(b_6\) 的名单上也恰好有 \(a_4\)、\(a_5\)，于是出现了两对错误的 MNN：\(a_4\)–\(b_6\) 与 \(a_5\)–\(b_6\)，配对向量分别为 \((2.5,\ -2.0)\) 与 \((2.0,\ -1.5)\)。

这两对错误配对造成两个后果。第一，T 细胞端全部 6 对的平均向量被拉偏到 \((1.15,\ -0.35)\)，与真实值相去甚远。第二，更严重的是 \(b_6\) 获得了自己的锚点，按其平均向量 \((2.25,\ -1.75)\) 校正后落在 \((5.25,\ 4.75)\)，恰好位于 \(a_4\) 与 \(a_5\) 之间。一种只存在于 STIM 中的新状态就这样被”整合”进了 T 细胞，这正是过度整合的机制。规律是：当 \(k\) 超过某种共享细胞类型在另一批次中的细胞数时，多出的名额只能分给其他类型，错误配对便随之产生。Seurat 寻找锚点时默认 k.anchor = 5，正是为了让每个细胞只与极少数最可信的伙伴配对。

39.6.1.5 Seurat 的过滤与打分

真实数据比上例复杂得多，Seurat 因此在 MNN 之后又加了两道关卡（Stuart et al., 2019）。第一道是过滤：锚点是在低维共享空间中找到的，Seurat 回到由锚点特征基因构成的高维表达空间复核：若锚点一端的细胞不在另一端细胞于对方数据集中的前 200 个近邻之内（k.filter = 200），该锚点即被剔除。第二道是打分：对每个锚点，Seurat 统计其两端细胞在两个数据集中各自 30 个近邻（k.score = 30）的重叠程度，再把得分按分位数缩放到 0–1 之间。得分高，说明两个细胞不仅彼此相邻，各自所处的”邻里”也相互对应。这一思路与 SNN 的 Jaccard 权重相同（参见专题 6.3）。最后，在计算每个细胞的校正量时，只使用离它最近的 100 个锚点（IntegrateData() 的 k.weight = 100）。

CCA 在 CTRL 与 STIM 之间找到 8,909 个锚点，其中 90.0% 连接同一种细胞类型；RPCA 只找到 4,659 个，同类比例为 87.5%。RPCA 的锚点数约为 CCA 的一半，这是”条件更严、更保守”的直接体现。两种方法下，参与锚点的 CTRL 细胞分别只有 5,603 个（46%）与 3,254 个（27%）。与上例中的 \(a_1\) 一样，多数细胞的校正量借自附近的锚点。

跨类型的锚点并非随机分布。以 CCA 为例，CD8 T 细胞的锚点有 17.7% 连到 NK 细胞、12.8% 连到 CD4 T 细胞；树突状细胞的锚点有 12.6% 连到 CD14+ 单核细胞；CD14+ 单核细胞与 FCGR3A+ 单核细胞之间也互有约 8% 的锚点。这些都是转录组上连续过渡的相邻类型：CD8 效应 T 细胞与 NK 细胞共享细胞毒性程序，两类单核细胞之间存在中间状态。因此，这类”错配”相当一部分反映的是注释边界本身的模糊，而不是整合算法把截然不同的细胞对齐了。与之形成对照的是，B 细胞、CD4 T 细胞与 NK 细胞的锚点同类比例都在 92% 以上。

还有一点值得说明。锚点得分并不能把这些跨类型锚点筛出来：把 CCA 锚点按得分分为五档，各档的同类比例都在 86%–92% 之间，没有随得分升高而上升。这与专题 6.3 中 SNN 权重能够预示近邻关系可重复性的结果不同。原因在于，跨类型锚点集中在相邻类型的过渡区域，那里的细胞在近邻结构上本就彼此交织，“邻里对应”的程度与同类配对相当。锚点得分衡量的是局部结构是否一致，而不是细胞类型标签是否相同。

39.6.2 Harmony：在嵌入空间中迭代”聚类—校正”

Harmony 不处理基因表达矩阵，而是直接在 PCA 嵌入上工作。它交替执行两步，直至收敛。

第一步是最大多样性聚类（maximum diversity clustering）。Harmony 对细胞做软 \(k\)-means 聚类，每个细胞 \(i\) 以概率 \(R_{ki}\) 隶属于聚类 \(k\)。与普通软聚类不同，其目标函数额外加入一个多样性惩罚。若某聚类中批次 \(b\) 的观测细胞数 \(O_{kb}\) 多于按全局比例应有的期望数 \(E_{kb}\)，则来自批次 \(b\) 的细胞被分配到该聚类的概率会受到惩罚，大致满足

\[ R_{ki} \propto \exp\!\left(-\frac{\lVert z_i - y_k \rVert^2}{\sigma}\right)\left(\frac{E_{k b_i}}{O_{k b_i}}\right)^{\theta} \]

其中 \(z_i\) 为细胞的嵌入坐标，\(y_k\) 为聚类中心，\(\sigma\) 控制软聚类的”软”度，\(\theta\) 控制多样性惩罚的强度。\(\theta = 0\) 时退化为普通软聚类；\(\theta\) 越大，聚类越被迫在各批次间均匀混合。

第二步是混合专家线性校正（mixture of experts correction）。对每个聚类 \(k\)，以 \(R_{ki}\) 为权重，用带岭惩罚 \(\lambda\) 的线性模型估计该聚类内各批次的平均偏移 \(W_k\)。随后从每个细胞的坐标中减去其所属各聚类偏移的加权和：

\[ \hat z_i = z_i - \sum_k R_{ki}\, W_k^{\top}\phi_i \]

\(\phi_i\) 为细胞 \(i\) 的批次指示向量（不含截距）。由于偏移是按聚类分别估计的，Harmony 允许不同细胞类型具有不同方向与大小的批次效应。这正是它优于”整体减去批次均值”一类全局线性校正的原因。

39.6.3 scVI：把批次写进生成模型

scVI 把整合问题改写为概率建模问题。它假设每个细胞 \(n\) 的原始计数由一个低维隐变量 \(z_n\) 与批次标签 \(s_n\) 共同生成：

\[ z_n \sim \mathcal{N}(0, I), \qquad \rho_n = f_w(z_n, s_n), \qquad x_{ng} \sim \mathrm{NB}\!\left(\ell_n \rho_{ng},\ \theta_g\right) \]

其中 \(f_w\) 是解码器神经网络，输出经 softmax 归一化的基因表达比例 \(\rho_n\)；\(\ell_n\) 为文库大小；\(\theta_g\) 为基因特异的离散度参数（负二项模型的含义参见第 4 章）。编码器网络 \(q(z_n \mid x_n, s_n)\) 近似隐变量的后验分布。两者通过最大化证据下界（ELBO）联合训练，这一结构即变分自编码器（Variational Autoencoder, VAE），其基本结构见 图 3。

批次校正的关键在于：解码器已经”知道”批次 \(s_n\)，能够自行解释由批次引起的表达差异，于是隐变量 \(z_n\) 无需、也不应再编码批次信息。训练完成后，\(z_n\) 即为批次校正后的低维表示，可直接用于构建近邻图、聚类与 UMAP。scVI 还能在解码时把所有细胞的批次标签统一设为同一个值，生成”假如都在同一批次中测量”的归一化表达。与 Harmony 相比，scVI 直接对原始计数建模，能捕捉非线性的批次效应，并自然扩展到半监督注释（scANVI，参见专题 6.3）与参考映射。代价是需要 Python 与 PyTorch 环境，训练耗时较长，且结果受随机初始化与训练轮数影响。

下一节的定量评估显示，按供体整合后，条件的局部混合度与未校正时完全相同，16 个聚类中仍有 10 个超过 90% 的细胞来自同一条件。原因在于主成分回归早已表明：供体效应很弱，条件才是主导变异。Harmony 只会消除被告知的变量。若指定的变量本来就混合良好，算法几乎无事可做，真正的批次结构则原封不动地保留下来。选择整合变量之前，先做诊断。

39.10 整合质量评估

39.10.1 LISI：用局部邻域衡量混合与分离

整合的目标是在”混合批次”与”保留生物学结构”之间取得平衡。两类指标分别量化这两个目标。局部逆辛普森指数（Local Inverse Simpson’s Index, LISI）是其中最常用的一种（Korsunsky et al., 2019）。对每个细胞，LISI 先在嵌入空间中取其近邻（以高斯核按距离加权），统计近邻中各类别的比例 \(p_1, \dots, p_B\)，再计算

\[ \mathrm{LISI} = \frac{1}{\sum_{b=1}^{B} p_b^2} \]

LISI 可理解为”该细胞邻域中有效的类别数”。若邻域全部来自同一类别，LISI = 1；若 \(B\) 个类别等比例混合，LISI = \(B\)。同一公式对不同标签有不同解读：

  • iLISI（integration LISI）：以批次为标签，衡量批次混合度，越高越好，上限为批次数。kBET 是另一种基于卡方检验的批次混合度指标，思路相近（Büttner et al., 2019）。
  • cLISI（cell-type LISI）：以细胞类型为标签，衡量生物学保真度，越接近 1 越好（邻域内细胞类型纯净）。

二者构成此消彼长的权衡：过度整合（over-correction）会人为合并不同的细胞类型，表现为 iLISI 升高但 cLISI 恶化。

安装说明： lisi 包需从 GitHub 安装：remotes::install_github("immunogenomics/lisi")。在较新的 R 与 RcppArmadillo 组合下，其 src/Makevars 中的 CXX_STD = CXX11 一行会导致编译失败。解决办法是下载源码，删除该行后用 R CMD INSTALL 安装。macOS 上若未安装 gfortran，还需从同一文件的 PKG_LIBS 中删去 $(FLIBS)。

# Adjusted Rand index between two labelings
ari <- function(a, b) {
    tab <- table(a, b); n <- sum(tab)
    s  <- sum(choose(tab, 2))
    sa <- sum(choose(rowSums(tab), 2)); sb <- sum(choose(colSums(tab), 2))
    e  <- sa * sb / choose(n, 2)
    (s - e) / ((sa + sb) / 2 - e)
}

      ARI_cell       = round(ari(obj$seurat_clusters, obj$cell), 3),
      condition_pure = sum(apply(cond_share, 1, max) > 0.9))
}

39.10.2 压力测试：当某种细胞只存在于一个批次

判断是否过度整合的实操方法： 整合后检查已知标志基因的表达是否仍在预期的细胞类型中特异分布。例如，若整合后 CD3D（T 细胞）与 LYZ（单核细胞）的表达边界变得模糊，或两个本应分开的细胞类型簇被强行合并，则提示过度整合。对生物学差异较大的样本，优先选用更保守的 RPCA 而非 CCA。压力测试与标志基因检查互为补充：前者检验算法在”无对应物”时的行为，后者检验真实数据上的生物学结构是否保留。

39.11 整合结果的使用边界

整合产出的是一个用于”找邻居”的坐标系，而不是一份新的表达数据。这一区分决定了整合结果能做什么、不能做什么。

校正后的嵌入（Harmony、RPCA/CCA 的降维输出、scVI 隐变量）适用于构建近邻图、聚类、UMAP 可视化、细胞类型注释与标签传递，以及下文 miloR 差异丰度分析所需的 KNN 图。它们不适用于差异表达：Harmony 从不修改表达矩阵，整合前后 data layer 中的数值完全相同。在本数据中，CD14+ 单核细胞的 ISG15 对数归一化表达均值在 CTRL 中为 0.69，在 STIM 中为 6.09；IFI6 分别为 0.53 与 3.31。整合后这些数值不变，条件效应完整保留在表达矩阵中，留待差异表达分析检验。

# Harmony only changes the embedding: expression values are untouched
mono_cells <- colnames(kang)[kang$cell == "CD14+ Monocytes"]
isg <- FetchData(kang, vars = c("ISG15", "IFI6", "stim"),
                 cells = mono_cells, layer = "data")
aggregate(cbind(ISG15, IFI6) ~ stim, data = isg, FUN = mean)

不要在”校正后的表达值”上做差异表达： Seurat v4 IntegrateData() 生成的 integrated assay、removeBatchEffect() 的输出与 scVI 的归一化表达，都是经过模型变换的数值。它们之间不再相互独立，也不再服从计数分布；校正过程还可能把条件差异部分地当作批次效应扣除。用这些数值做差异检验，P 值没有意义。正确的做法是：用校正后的嵌入确定细胞身份，再回到原始计数，把批次或供体作为协变量写进差异表达模型（参见第 4 章”在设计矩阵中包含批次变量”）。

40 多样本差异表达：拟bulk方法

40.1 伪重复问题

获得整合后的细胞图谱并完成注释后，一个常见目标是检验某细胞类型在两种条件间的差异表达基因。直觉上似乎可以直接用 FindMarkers() 的 Wilcoxon 检验，把”细胞”当作样本逐个比较。这是单细胞差异分析中最常见的统计错误。

问题在于伪重复（pseudo-replication）：同一供体的数千个细胞并非相互独立的观测，它们共享该供体的遗传背景、处理批次与技术状态。把细胞当作独立重复，等于把样本量从”几个供体”虚增到”几千个细胞”，导致方差被严重低估、P 值极度偏小。多项基准研究表明，逐细胞检验会产生大量假阳性，其”显著基因”很多只反映个别供体的特异性，而非可重复的条件效应（Squair et al., 2021）。

“伪重复”一词的来历： 这个术语并非源自基因组学，而是来自生态学。1984 年，生态学家 Stuart Hurlbert 在《Ecological Monographs》上发表了一篇关于野外实验设计的长文，系统梳理了当时生态学文献中的统计错误。他把”处理只施加于一个实验单元，却把该单元内的多次测量当作独立重复”的做法命名为伪重复。例如，只在一个池塘里施肥，却把从该池塘采集的十份水样当作十个重复。三十多年后，单细胞研究以几乎相同的形式重现了这个错误：一个供体就是一个”池塘”，它的数千个细胞就是同一池塘里的水样。

黄金法则： 多样本差异表达的统计重复单位是生物学样本（供体），而不是细胞。任何把成千上万个细胞当作独立重复的检验，都会因伪重复而产生不可重复的假阳性。正确的做法是先将细胞聚合为拟bulk，再以样本为单位做检验。这与 图 4 中的区组法同理：一个供体就是一个区组。

40.2 量化伪重复：组内相关与设计效应

伪重复的危害可以精确地量化。设某基因在供体 \(j\) 的细胞 \(i\) 中的表达为 \(y_{ij}\)，其总方差 \(\sigma^2\) 可分解为供体间方差 \(\sigma_b^2\) 与供体内（细胞间）方差 \(\sigma_w^2\) 两部分。二者之比定义为组内相关系数（Intraclass Correlation Coefficient, ICC）：

\[ \rho = \frac{\sigma_b^2}{\sigma_b^2 + \sigma_w^2} \]

\(\rho\) 衡量同一供体的两个细胞彼此”有多像”。若每名供体贡献 \(m\) 个细胞、共 \(n\) 名供体，则组均值的方差为

\[ \mathrm{Var}(\bar y) = \frac{\sigma^2}{nm}\,\bigl[1 + (m-1)\rho\bigr] \]

方括号内的因子称为设计效应（design effect）。它表明，\(nm\) 个细胞所携带的信息量只相当于 \(nm / [1+(m-1)\rho]\) 个独立观测。当 \(m\) 很大时，有效样本量趋近于 \(n/\rho\)：无论每名供体测多少个细胞，信息量的上限都由供体数决定。逐细胞检验却假设 \(\rho = 0\)，即把设计效应当作 1。设计效应的概念最早来自抽样调查中的整群抽样（图 5）。

这个公式的威力在于：即便 \(\rho\) 很小，只要 \(m\) 足够大，设计效应依然可观。下面在 CTRL 条件的 CD14+ 单核细胞中，用单因素方差分析的矩估计计算各高变基因的 ICC：

counts_m <- LayerData(ctrl_mono, layer = "counts")
keep_g <- rowMeans(counts_m > 0) >= 0.10          # genes detected in >= 10% of cells
hvg <- intersect(VariableFeatures(kang), rownames(logn_m)[keep_g])

# One-way ANOVA estimator of the donor intraclass correlation
icc <- sapply(hvg, function(g) {
    x <- logn_m[g, ]; f <- droplevels(ctrl_mono$ind)
    a <- anova(lm(x ~ f))
    msb <- a$`Mean Sq`[1]; msw <- a$`Mean Sq`[2]
    n0 <- (length(x) - sum(table(f)^2) / length(x)) / (nlevels(f) - 1)
    sb2 <- max((msb - msw) / n0, 0)
    sb2 / (sb2 + msw)
})
quantile(icc, c(0.25, 0.5, 0.75, 0.9))
m_bar <- mean(table(ctrl_mono$ind))
1 + (m_bar - 1) * median(icc)                     # design effect at the median ICC

在 2,770 个 CTRL CD14+ 单核细胞中（各供体 112–779 个，平均 346 个），329 个检测率不低于 10% 的高变基因的 ICC 中位数仅为 0.017，四分位范围为 0.007–0.035。也就是说，对典型基因而言，供体差异只占细胞间总变异的不到 2%。然而代入设计效应公式，\(1 + (346 - 1) \times 0.017 \approx 6.8\)：这 2,770 个细胞所携带的信息只相当于约 400 个独立观测。逐细胞检验却把它们当作 2,770 个，标准误被低估约 \(\sqrt{6.8} \approx 2.6\) 倍。对 ICC 位于第 90 百分位（0.058）的基因，设计效应超过 20。

40.3 一个零假设实验：没有差异时会找到多少差异基因

设计效应给出了理论预期，零假设实验则给出直接证据。思路很简单：只取 CTRL 条件的细胞，把 8 名供体随机分成两组各 4 人，再比较这两组。由于所有细胞都未经处理，两组之间不存在任何真实的条件效应，任何”显著”基因都是假阳性。8 名供体分成两个 4 人组共有 \(\binom{8}{4}/2 = 35\) 种不同分法，可以全部枚举。

library(presto)
library(edgeR)

donors <- sort(unique(as.character(ctrl_mono$ind)))
# Pseudobulk: one column per donor (sum of raw counts)
pb_null <- sapply(donors, function(d)
    Matrix::rowSums(counts_m[keep_g, ctrl_mono$ind == d]))

# All 35 distinct 4-vs-4 partitions (fix the first donor in group A)
splits <- combn(donors, 4, simplify = FALSE)
splits <- splits[sapply(splits, function(s) donors[1] %in% s)]

null_res <- t(sapply(splits, function(grp_a) {
    # (a) Cell-level Wilcoxon: every cell is treated as a replicate
    w <- wilcoxauc(logn_m[keep_g, ], ifelse(ctrl_mono$ind %in% grp_a, "A", "B"))
    w <- w[w$group == "A", ]
    # (b) Pseudobulk edgeR: every donor is one replicate
    g <- factor(ifelse(donors %in% grp_a, "A", "B"))
    y <- DGEList(pb_null, group = g)
    y <- normLibSizes(y[filterByExpr(y, group = g), , keep.lib.sizes = FALSE])
    des <- model.matrix(~ g)
    fit <- glmQLFit(estimateDisp(y, des), des)
    tt  <- topTags(glmQLFTest(fit, coef = 2), n = Inf)$table
    c(wilcoxon   = sum(p.adjust(w$pval, "BH") < 0.05),
      pseudobulk = sum(tt$FDR < 0.05))
}))
summary(null_res)

40.4 拟bulk聚合的逻辑

拟bulk（Pseudobulk）方法的思想是：对每个样本、每种细胞类型，将其所有细胞的原始计数逐基因相加，得到一个”伪批量”表达谱。这样，一个 8 供体 × 2 条件的实验，对某细胞类型就得到 16 个拟bulk样本，恰好回到了经典 bulk RNA-seq 的统计框架，可直接套用 DESeq2/edgeR 的负二项模型（参见第 4 章）。

聚合时求和而非求平均，有两层原因。第一，求和保留了计数的整数性质与总测序深度，使负二项分布的均值-方差关系依然成立，DESeq2 的大小因子与离散度估计仍然适用。第二，不同样本中同一细胞类型的细胞数不同，求和后这一差异被吸收进文库大小，由归一化步骤处理；求平均则会丢失”该均值基于多少个细胞”的信息，使细胞多的样本与细胞少的样本被同等看待。聚合后样本间的变异自然反映了真实的生物学重复变异，从而给出校准良好的 P 值。

40.5 muscat 拟bulk差异分析实操

muscat 把”按样本 × 细胞类型聚合，再逐细胞类型做 bulk 差异检验”这一流程封装为几个函数（Crowell et al., 2020）。它要求三个元数据列：cluster_id（细胞类型）、sample_id（样本）与 group_id（条件），由 prepSCE() 统一命名。

sample_id 必须是”供体 × 条件”，而不是供体： 在配对设计中，每名供体同时贡献 CTRL 与 STIM 两个样本。若把 sid 直接设为供体编号 ind，则一个”样本”会同时包含两种条件的细胞，聚合后条件信息丢失。正确做法是先拼接出 stim + ind 形式的样本编号，得到 16 个样本，再把供体作为区组因子单独写进设计矩阵。

40.8 逐细胞检验与拟bulk的正面比较

回到本节开头的问题：在真实存在强烈条件效应的数据上，逐细胞 Wilcoxon 检验与拟bulk的结论有多大差别？在 CD14+ 单核细胞中，对检测率不低于 10% 的 1,695 个基因做 STIM 相对 CTRL 的逐细胞 Wilcoxon 检验，1,486 个（87.7%）达到 FDR < 0.05。其中 76 个基因的 P 值小到超出双精度浮点数的表示范围，被直接记为 0。在同一组 1,695 个基因上，配对拟bulk edgeR 判定 1,320 个显著。有 265 个基因只被 Wilcoxon 检验判为显著。

这一比较与零假设实验相互印证。当条件效应强大时，两种方法会共同检出大部分真实信号，差别集中在效应量较小、供体间不一致的基因上。正是这些基因构成了逐细胞检验多出来的部分。零假设实验已经表明，逐细胞检验在没有任何条件效应时也会报告数百个基因。因此，这 265 个”Wilcoxon 独有”基因中有多少是真实信号，无法从逐细胞检验本身得到回答。逐细胞检验的 P 值也失去了概率意义：一个 \(10^{-300}\) 的 P 值并不表示这一结果比 \(10^{-15}\) 可靠 \(10^{285}\) 倍，它只是细胞数被当作样本量的产物。

细胞数过少的细胞类型不可靠： 当某细胞类型在某些样本中细胞数很少时，其拟bulk计数受少数细胞主导，离散度估计不稳定。本数据中巨核细胞最少的样本只有 4 个细胞，在配对设计下已无法分析。实践中应在聚合前检查”细胞类型 × 样本”的细胞数表，通过 min_cells 参数剔除细胞数过低的样本，并在结果中标注受影响的细胞类型。不应为了”凑出结果”而把相近的细胞类型临时合并，那会改变所检验的生物学问题。

40.9 混合模型：另一条可行路径

拟bulk并非处理伪重复的唯一方法。另一条路径是保留细胞级数据，在模型中显式加入供体随机效应：

\[ y_{ij} = \beta_0 + \beta_1 \cdot \mathrm{condition}_j + u_j + \varepsilon_{ij},\qquad u_j \sim \mathcal{N}(0, \sigma_b^2) \]

随机效应 \(u_j\) 吸收了同一供体细胞的共享偏移，使条件效应 \(\beta_1\) 的标准误正确反映供体层面的变异。Zimmerman 等人用模拟与真实数据比较了两条路径，认为带供体随机效应的广义线性混合模型（GLMM）能够纠正伪重复偏差，而拟bulk方法在部分场景下过于保守（Zimmerman et al., 2021）。Murphy 与 Skene 随后用同时衡量假阳性与假阴性的平衡指标重新评估，得出拟bulk方法整体表现更优的相反结论（Murphy & Skene, 2022）。这场争论尚无定论，但双方在一点上完全一致：以细胞为独立重复的检验是错误的。

在实践中，两条路径的取舍主要取决于计算成本与研究问题（表 18）。muscat 的 mmDS() 函数提供了混合模型的实现（如 method = "dream"），可与 pbDS() 的结果相互对照。

FindMarkers() 仍有它的正当用途： 逐细胞检验并非一无是处。在单一样本中为聚类寻找标志基因时，研究问题是”这群细胞与其他细胞有何不同”，并不涉及推广到新供体，逐细胞检验作为排序工具是合理的（其双重浸入问题参见专题 6.3）。错误只发生在把它用于”条件 A 与条件 B 之间”这类需要以供体为单位推广的问题时。判断标准是：结论是关于这些细胞的，还是关于这类样本的。

41 差异丰度分析

41.1 组成数据的挑战

差异表达回答”基因变了多少”，差异丰度（Differential Abundance, DA）则回答”细胞类型的比例变了多少”，例如刺激后某个激活态细胞群是否扩张。最朴素的做法是统计每个样本中各细胞类型的比例，再做组间 t 检验。但这种做法有两个缺陷。

第一，依赖离散聚类。预先定义的细胞类型聚类可能掩盖聚类内部的连续状态变化。真正发生扩张的或许只是某聚类中的一个亚状态，而非整个聚类。

第二，组成数据的约束。各细胞类型比例之和恒为 1，因此一个类型的真实扩张会机械地压低其他所有类型的比例，产生虚假的”减少”信号。设某样本含 T 细胞 600 个、B 细胞 200 个、单核细胞 200 个；处理后单核细胞绝对数量翻倍为 400 个，T 与 B 细胞不变。比例随之从 60% / 20% / 20% 变为 50% / 16.7% / 33.3%。T 与 B 细胞的绝对数量没有任何变化，比例却分别下降了 10 与 3.3 个百分点。这种”此消彼长”是组成数据（compositional data）分析的核心难题：比例数据落在一个总和恒定的单纯形上（图 6），不能直接套用欧氏空间的统计方法。单细胞测序只能捕获每个样本的一部分细胞，观测到的天然就是比例而非绝对数量，因此这一约束无法通过增加测序深度来消除。

41.2 细胞类型层面：propeller 比例检验

在已定义的细胞类型层面，propeller 是一种简单而稳健的检验方法（Phipson et al., 2022）。它先计算每个样本中各细胞类型的比例，再做 logit 或反正弦平方根变换以稳定方差，最后用 limma 的经验贝叶斯线性模型逐细胞类型检验。由于以样本比例为观测值，propeller 天然以样本为重复单位，并能通过设计矩阵纳入配对结构：

library(speckle)
library(limma)

md <- kang@meta.data

# Per-sample cell-type proportions (%)
round(100 * prop.table(table(md$sample, md$cell), 1), 1)

# (a) Unpaired comparison
propeller(clusters = md$cell, sample = md$sample, group = md$stim,
          transform = "logit")

# (b) Paired comparison: donor as a blocking factor in the design
props <- getTransformedProps(md$cell, md$sample, transform = "logit")
smp   <- colnames(props$TransformedProps)
grp   <- factor(sub("_.*", "", smp))
donor <- factor(sub(".*_", "", smp))
des   <- model.matrix(~ 0 + grp + donor)
propeller.ttest(props, design = des,
                contrasts = c(1, -1, rep(0, ncol(des) - 2)),
                robust = TRUE, trend = FALSE, sort = TRUE)

各样本的细胞组成首先显示出巨大的供体差异。CD8 T 细胞的比例在多数样本中为 2%–9%，供体 1016 却高达 31.1%（CTRL）与 29.9%（STIM）。CD4 T 细胞的比例也在 21.6%–58.3% 之间变动。相比之下，同一供体两种条件之间的差别很小。非配对检验中，8 种细胞类型的 FDR 均大于 0.8，没有任何类型达到显著。配对检验消除了供体间差异后，CD8 T 细胞的比例从 8.6% 降至 7.7%，FDR = 0.035，达到显著；NK 细胞从 7.2% 升至 8.5%，未校正 P = 0.036，但 FDR = 0.14。

这个”显著”结果需要谨慎解读。体外刺激只有 6 小时，细胞几乎不可能在如此短的时间内增殖或分化，真实细胞数量发生改变的可能性很低。更可能的解释有两种：一是刺激改变了不同细胞类型的存活率或被捕获的效率；二是干扰素诱导的转录变化使部分细胞跨过了注释边界。CD8 T 细胞的下降与 NK 细胞的上升恰好方向相反、幅度相近，而二者共享多种细胞毒性基因，后一种解释尤其值得怀疑。统计检验只能回答”观测到的比例是否不同”，无法回答”为什么不同”。比例差异的生物学解读，必须结合实验时间尺度与注释的稳定性。

41.3 scCODA：带参考细胞类型的贝叶斯组成模型

propeller 逐细胞类型独立检验，并未显式处理组成约束。scCODA 则用贝叶斯狄利克雷-多项式模型对全部细胞类型的计数联合建模（Büttner et al., 2021）。它要求指定一个”参考细胞类型”，假设该类型的绝对丰度在条件间不变，其他类型的变化都相对于它来表达，以此锚定组成约束。参考类型的选择会影响结论，应选择在所有样本中都存在、且生物学上预期不受处理影响的类型。

41.4 miloR 邻域差异丰度检验

miloR 通过两项设计绕开了离散聚类与组成约束的局限（Dann et al., 2022）。其一，它不依赖离散聚类，而是在 KNN 图上定义大量相互重叠的邻域（neighborhood），每个邻域是一个代表细胞及其近邻。miloR 在邻域这一精细尺度上检验丰度变化，从而捕捉连续状态的扩张或收缩。其二，它用负二项广义线性模型（NB-GLM）对每个邻域内各样本的细胞计数建模，以样本为重复单位，并用加权的空间 FDR（SpatialFDR）校正邻域间的重叠与多重检验。

library(miloR)
library(SingleCellExperiment)

# Build the Milo object on the Harmony embedding (see below for why)

milo <- Milo(sce_milo)
milo <- buildGraph(milo, k = 30, d = 30, reduced.dim = "HARMONY")

# Sample 5% of cells as neighbourhood indices (refined sampling is random)
set.seed(42)
milo <- makeNhoods(milo, prop = 0.05, k = 30, d = 30, refined = TRUE,
                   reduced_dims = "HARMONY")

# Count cells from each of the 16 samples within each neighbourhood

# One row per sample; paired design with donor as a blocking factor

rownames(design_df) <- design_df$sample

milo <- buildNhoodGraph(milo)
da_results <- testNhoods(milo, design = ~ ind + stim, design.df = design_df,
                         reduced.dim = "HARMONY", fdr.weighting = "graph-overlap")

# Label each neighbourhood with its majority cell type
da_results <- annotateNhoods(milo, da_results, coldata_col = "cell")
table(da_results$SpatialFDR < 0.1, sign(da_results$logFC))

41.4.1 嵌入空间的选择决定了 DA 检验在问什么

miloR 的邻域建立在 KNN 图之上，而 KNN 图取决于所用的嵌入。在本数据中分别用未校正 PCA 与 Harmony 嵌入运行同一流程，结论截然不同（表 19）。

在未校正嵌入中，94.4% 的邻域超过 90% 的细胞来自同一条件，因此几乎每个邻域都”显著”。这些结果的含义是”STIM 细胞与 CTRL 细胞位于表达空间的不同位置”，它描述的是表达状态的改变，而非丰度的改变。把它报告为差异丰度，就是把差异表达信号重复计算了一遍。在 Harmony 嵌入中，两种条件的同类细胞被对齐，条件纯邻域降至 10.0%，显著邻域的比例也降至一半左右。邻域代表细胞的抽样带有随机性，重复运行时邻域数与显著邻域数会小幅波动（另一次独立运行得到 937 个邻域、459 个显著，其中上升 256 个、下降 203 个），但显著比例与方向分布基本不变。

DA 分析的嵌入选择没有中性答案： 用未校正嵌入，DA 会把表达状态的改变误报为丰度改变；用整合后的嵌入，若整合过度，真正只存在于某一条件的新细胞状态可能被并入已有状态，导致真实的 DA 被抹去。实践中应以整合嵌入为主，同时检查显著邻域在细胞类型内部是单向还是双向分布，并与 propeller 等细胞类型层面的结果对照。若研究的核心问题是”刺激是否诱导出新的细胞状态”，应在未整合的数据中单独检查该状态是否只存在于一种条件。

差异表达与差异丰度的互补解读： 一个条件效应可能表现为差异丰度（某细胞类型扩张）、差异表达（某细胞类型内部基因上调），或两者兼有。本数据给出了一个清晰的例子：IFN-β 刺激 6 小时后，各细胞类型内部有数百至数千个基因显著变化（DE），细胞类型层面的组成却几乎不变（DA）。邻域层面的大量显著结果，主要是 DE 在嵌入空间中留下的残余，而不是独立的丰度信号。完整的多样本分析应同时报告这两个层面，并说明二者如何相互印证。

42 方法总结与衔接说明

本专题确立了多样本单细胞分析的统计基石，并在同一份数据上逐一验证。第一，先诊断，再整合：主成分回归显示 Kang18 的主要技术变异来自与条件耦合的文库，而非供体；按错误的变量整合不会产生任何效果。第二，整合的目的是统一坐标系：Harmony、RPCA 与 CCA 都消除了条件纯聚类，且未合并细胞类型；压力测试表明，在存在非共享细胞类型时，CCA 是三者中最不保守的。整合结果只用于找邻居，差异表达必须回到原始计数。第三，细胞不是重复，样本才是重复：零假设实验中，逐细胞 Wilcoxon 检验在 35 种分组下全部报告了上百个假阳性基因，拟bulk edgeR 则几乎全部为零。即使 ICC 只有 0.017，每名供体数百个细胞也会带来约 6.8 倍的设计效应。第四，配对设计应写进模型：供体区组因子使 BCV 下降约三分之一，muscat 与 DESeq2 的结论高度一致。第五，丰度变化与状态变化要分开：嵌入空间的选择决定了 miloR 在检验什么，6 小时刺激下的”显著”组成变化需要结合时间尺度与注释稳定性解读。

整合后的统一图谱是后续所有高级分析的共同输入。专题 7.2 将在此基础上重建细胞分化的拟时序轨迹；本专题看到的”同一细胞类型内部的状态迁移”，正是拟时序与 RNA Velocity 试图刻画的连续变化。专题 7.3 推断细胞通讯与调控网络，本专题检出的干扰素响应基因将在那里与 STAT/IRF 家族调控子相互印证。第 9 章则以注释后的图谱作为空间解卷积的参考（参见第 9 章）。

参考答案 (Reference Answers)

  1. 批次效应是处理时间、文库制备批次、测序批次、化学版本等非生物学因素引入的系统性技术变异；供体差异本身属于生物学变异，只有在与技术流程耦合时，样本标签才同时混入两类来源。当不同样本的同类细胞被这些技术因素系统性地偏移时，技术变异的幅度可能与细胞类型间的生物学差异相当甚至更大，于是 PCA 的若干主要方向捕捉的是”样本/批次”而非”细胞类型”，聚类首先按样本分开。

  2. 由于 8 名供体的细胞在同一文库中被一起处理，供体与文库批次解耦，供体间差异不可能来自文库，这为以供体为重复单位的检验提供了干净基础；同时每名供体出现在两种条件中，构成 8 对配对设计。但 CTRL 与 STIM 分别上样、分别建库，条件与文库批次完全混杂，因此任何”STIM 相对 CTRL”的差异严格来说都是 IFN-β 效应与文库效应之和。IFN-β 效应极强，主要结论可信，但效应量小的基因无法排除文库效应的干扰。

  3. 为统一共享细胞类型的注释，后续按条件（与文库耦合）整合，因为条件标签关联了 PC2 与 PC8 的较多变异。该回归只说明关联，不能证明这些变异都是技术来源，也不能拆分条件与文库效应。若误按供体整合，Harmony 只会消除供体差异，而供体本来就混合良好，算法几乎无事可做；实测中条件 iLISI 仍为 1.000，16 个聚类中有 10 个仍几乎只含单一条件，真正的批次结构原封不动。

  4. 每个基因只有一个批次系数的全局加性模型，无法同时拟合不同细胞类型各自的批次偏移。若又未在设计中保护类型结构，组成差异还会被当作批次效应扣除；加入类型主效应能保护本例标志信号，但不等于加入类型与批次的交互项。bulk 混合组织也可能有这些问题。Harmony 先做带多样性惩罚的软聚类，再在各聚类中按隶属概率加权估计批次相关回归，从而允许不同局部状态采用不同的校正。

  5. 若批次 1 的细胞 a 位于批次 2 细胞 b 的 k 近邻之内，同时 b 也位于 a 在批次 2 中的 k 近邻之内，则二者构成一对 MNN。批次独有的细胞类型在另一批次中没有相似的细胞，其最近邻即使存在，也不会反过来把它当作最近邻，因此无法形成”互相认可”的配对。CCA 在两个数据集相关性最大的共享投影空间中找 MNN；RPCA 把每个数据集分别投影到对方的 PCA 空间中找近邻，要求锚点在双方各自的主成分空间中都成立，条件更严，所以更保守、更不易把不同细胞类型对齐。

  6. 解码器已经接收批次标签，能自行解释由批次引起的表达差异，因此隐变量无需再编码批次信息；以 ELBO 训练后，z 主要保留与批次无关的生物学变异，可作为校正后的低维表示。scVI 的优势是直接对原始计数建模、能捕捉非线性批次效应，并可扩展到 scANVI 半监督注释与参考映射；代价是需要 Python/PyTorch 环境，训练耗时长，大数据通常需要 GPU，且结果受随机初始化与训练轮数影响。

  7. LISI = 1 / Σ p_b²，其中 p_b 为细胞邻域中（按距离高斯加权）类别 b 的比例，可理解为邻域中的有效类别数。iLISI 以批次为标签衡量批次混合度，越高越好，上限为批次数；cLISI 以细胞类型为标签衡量生物学保真度，理想值接近 1。本数据的条件只有 CTRL 与 STIM 两个水平，邻域中最多有两个等比例类别，因此条件 iLISI 的上限为 2。

  8. 它检验算法在”某细胞类型没有对应物”时是否会强行为其寻找错误伙伴，即过度整合的倾向。结果中，所有方法下 STIM 单核细胞仍有 93% 以上的近邻来自 STIM 自身，少量 CTRL 近邻也主要是最相近的 FCGR3A+ 单核细胞。CCA 被”多数 CTRL 近邻”包围的细胞比例最高（2.7%），是 Harmony（0.5%）的 5 倍以上，与”CCA 较不保守、RPCA 更保守”的经验一致。
